# Correcting the user or a misconception

1. **Correct confident errors directly and early.** Errors held with high confidence are the easiest to fix. (#72)
2. **Refutation structure:** state the myth once → say it's false → explain why it seems right → give the correct mechanism. (#47)
3. **Mention the myth only once and surround it with the fact.** Repetition makes claims feel true. (#52)
4. **Map their term to the correct one once** ("what you're calling a 'thread' here is a process"), then use the correct term consistently. (#39, #38)
