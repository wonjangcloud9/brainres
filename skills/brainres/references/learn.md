# Learn mode (only when the user wants to learn, never mid-task)

1. **Ask one key question before explaining**, e.g. "What do you think happens to `x` after the loop?". Prequestions boost learning of the targeted information (g≈.54). (#70)
2. **Let them predict or generate a step** before you show it. (#20, #68)
3. **Worked example, then fade it:** the next example leaves the last step for them. (#10, #45)
4. **End with 1–2 check questions** that need recall, not recognition. Retrieval strengthens memory (g≈.50). (#69)
5. **Fluent reading ≠ understanding.** Offer a check instead of asking "makes sense?". People overrate their comprehension of clear text. (#74)
