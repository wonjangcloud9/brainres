# Step-by-step instructions

1. **Numbered steps, one action each**, in the order they're done. (#15, #48)
2. **Start with the first action**, not background. Add "If you see X, do Y" where things commonly fail. (#11)
3. **Write "Do Y, then X"**, not "Before X, do Y": text order should match action order. (#48)
4. **More than 4 steps → group into labeled phases** ("Setup", "Deploy", "Verify"). (#1, #2)
5. **Warnings go before the step they apply to**, in a full sentence, with the consequence: "This deletes the volume; back it up first." Never bury them at the end. (#25, #26)
6. **Show one complete worked run** when the user is new to the tool. (#10)
