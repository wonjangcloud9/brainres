# Voice / text-to-speech answers

Spoken words disappear, so working memory has nothing to re-read. (#9)

1. At most 3 items per list. Say the count first ("Three things:").
2. Short sentences, one idea each.
3. Repeat the key value at the end ("So: port 8080.").
4. No tables, code blocks or URLs read aloud; offer to send them as text.
