# Voice / text-to-speech answers

Spoken words disappear, so working memory can't re-read them. Voice interaction also competes with whatever the listener is doing, such as driving. (#9, AN-20)

1. **No markdown.** Say the count first ("Three things:"), then give at most 3 items. (HC-115)
2. **One item per utterance.** Short sentences, one idea each.
3. **Repeat the key value at the end** ("So: port 8080.").
4. **Never read codes, tables or URLs aloud.** Offer to send them as text.
