<!-- Q: 도커랑 가상머신 차이가 뭐야? -->

도커는 호스트 OS의 커널을 공유하는 프로세스 단위 격리이고, 가상머신은 하이퍼바이저 위에 게스트 OS를 통째로 올리는 하드웨어 단위 격리예요.

| 항목 | 도커 컨테이너 | 가상머신 |
|---|---|---|
| 커널 | 호스트와 공유 | VM마다 별도 |
| 시작 시간 | 보통 1초 안팎 | 수십 초에서 수 분 |
| 크기 | 수십~수백 MB | 수 GB |
| 격리 강도 | 약함 (커널 취약점이 공유됨) | 강함 |
| 다른 OS 실행 | 불가 (Linux 컨테이너는 Linux 커널 필요) | 가능 |

**컨테이너는 커널을 공유해서** 가볍고 빠르지만, 그만큼 격리가 약해요. 반대로 VM은 OS를 따로 돌리니 무겁지만 보안 경계가 더 단단해요.

맥에서 도커를 쓰면 내부적으로 작은 Linux VM이 돌고, 그 안에서 컨테이너가 실행돼요. 맥 커널은 Linux 컨테이너를 직접 돌릴 수 없기 때문이에요.

선택 기준은 간단해요. 같은 OS 위에서 앱을 빠르게 띄우고 배포하려면 도커, 다른 OS가 필요하거나 강한 격리가 필요하면 VM이 맞아요. 직접 확인하려면 `docker run --rm alpine uname -r`을 실행해 보세요. 호스트(또는 도커 VM)와 같은 커널 버전이 나와요.
