# Reading benchmark

Do people understand brainres answers faster and as well as Claude's default answers? This folder holds the pre-registered human study: [PROTOCOL.md](PROTOCOL.md).

## Take it (about 10 minutes)

Open [`index.html`](index.html) in a browser. Any of these works:

- **Locally:** download the repo and double-click `bench/index.html`.
- **Hosted:** use GitHub Pages if the repo owner has enabled it (Settings → Pages → branch `main`, root), at `https://wonjangcloud9.github.io/brainres/bench/`.
- **Without Pages:** use a static preview such as `https://htmlpreview.github.io/?https://github.com/wonjangcloud9/brainres/blob/main/bench/index.html`.

You'll read 8 English or 4 Korean answers. You won't be told which version each answer is. For each one you answer a "find" question with the answer visible and an "understand" question with the answer hidden.

## Submit

The last screen shows a JSON result. [Open a "Benchmark result" issue](https://github.com/wonjangcloud9/brainres/issues/new?template=benchmark-result.yml) and paste it in. The result contains only a random ID, your choices, confidence ratings and timings.

## For maintainers

- `index.html` is generated by `scripts/build_dist.py` from `template.html` and the frozen `items/` (hash in `items/MANIFEST.sha256`), so it can't drift from the pre-registration.
- `validate.sh` loads `index.html#autotest` in headless Chrome. The test clicks through the whole study and checks that the result has a balanced 50/50 split of versions.
- The analysis script is backlog item B10-4. It follows the plan in PROTOCOL.md.
