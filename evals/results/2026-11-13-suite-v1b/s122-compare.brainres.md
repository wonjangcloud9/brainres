<!-- Q: 프로세스랑 스레드 차이가 뭐예요? -->

프로세스는 독립된 메모리 공간을 가진 실행 단위이고, 스레드는 한 프로세스 안에서 메모리를 공유하며 실행되는 더 작은 단위예요.

| 구분 | 프로세스 | 스레드 |
|---|---|---|
| 메모리 | 코드, 데이터, 힙, 스택을 각자 가짐 | 코드, 데이터, 힙은 공유하고 스택만 따로 가짐 |
| 생성 비용 | 큼 | 작음 |
| 통신 | IPC(파이프, 소켓, 공유 메모리)가 필요함 | 변수를 바로 공유함 |
| 문제 격리 | 한 프로세스가 죽어도 다른 프로세스는 안전함 | 한 스레드가 죽으면 프로세스 전체가 죽을 수 있음 |
| 동기화 | 거의 필요 없음 | 락, 뮤텍스가 필요함 |

**스레드는 힙을 공유하므로 데이터 경쟁(race condition)이 생길 수 있어요.** 두 스레드가 같은 변수를 동시에 바꾸면 결과가 꼬이기 때문에 락으로 보호해야 해요.

예를 들어 크롬은 탭마다 프로세스를 따로 써요. 한 탭이 죽어도 브라우저 전체는 살아남기 위해서예요. 반대로 웹 서버는 요청마다 스레드를 만들어 캐시 같은 메모리를 공유해요.
