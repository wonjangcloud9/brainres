<!-- Q: 이 스크립트 설명해줘

```bash
find . -name '*.log' -mtime +7 -print0 | xargs -0 gzip
``` -->

이 명령어는 현재 디렉터리와 그 하위 디렉터리에서 7일 이상 지난 `.log` 파일을 찾아 gzip으로 압축하는 스크립트입니다. 한 줄씩 나눠 보면 다음과 같습니다.

```bash
find . -name '*.log' -mtime +7 -print0 | xargs -0 gzip
```

| 부분 | 설명 |
|---|---|
| `find .` | 현재 디렉터리(`.`)부터 하위 경로까지 모두 탐색합니다. |
| `-name '*.log'` | 파일 이름이 `.log`로 끝나는 파일만 대상으로 합니다. 작은따옴표는 셸이 와일드카드를 미리 확장하지 않도록 막습니다. |
| `-mtime +7` | 마지막 수정 시각이 7일보다 오래된 파일만 고릅니다. (`+7`은 "7일 초과", 즉 8일 이상 지난 파일을 뜻합니다.) |
| `-print0` | 파일 경로를 줄바꿈 대신 널 문자(`\0`)로 구분해 출력합니다. 공백이나 줄바꿈이 들어간 파일명도 안전하게 처리됩니다. |
| `\|` | `find`의 출력을 `xargs`의 입력으로 넘깁니다. |
| `xargs -0` | 널 문자로 구분된 입력을 읽습니다. `-print0`과 짝을 이룹니다. |
| `gzip` | `xargs`가 받은 파일들을 각각 gzip으로 압축합니다. 압축하면 원본 파일은 `파일명.log.gz`로 바뀌고 원본 `.log`는 삭제됩니다. |

**요약하면**: 현재 위치 아래에 있는 8일 이상 된 로그 파일을 모두 찾아서 `.gz`로 압축하는 명령입니다. 디스크 공간을 줄이고 오래된 로그를 보관하는 용도로 자주 쓰입니다.

**주의할 점**
- 압축 후 원본 `.log` 파일은 사라집니다. 원본을 남기고 싶다면 `gzip -k`를 쓰거나 백업을 먼저 해두세요. (`-k`는 macOS의 gzip에서도 지원됩니다.)
- 실행 중인 프로그램이 쓰고 있는 로그를 압축하면 문제가 생길 수 있습니다. 예를 들어 서비스가 계속 같은 파일에 기록하는 경우입니다.
- 명령을 실행하기 전에 `find . -name '*.log' -mtime +7 -print`로 대상 목록을 먼저 확인해 보는 것을 권장합니다.
- 이 명령은 `-mtime`을 쓰므로 macOS(BSD `find`)와 Linux(GNU `find`) 모두에서 동작합니다.
