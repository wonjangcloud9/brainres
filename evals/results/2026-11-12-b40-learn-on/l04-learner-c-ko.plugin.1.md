<!-- Q: C 배우는 중이에요. 평균을 구하는데 소수점이 안 나와요.

```c
int sum = 7;
int n = 2;
double avg = sum / n;
printf("%f\n", avg);
``` -->

`sum / n`이 `7 / 2`인데 둘 다 `int`라서 정수 나눗셈으로 `3`이 먼저 나오고, 그 `3`이 `double`에 담겨 `3.000000`이 출력돼요.

나누기는 대입보다 먼저 계산돼요. 피연산자가 둘 다 정수면 결과도 정수라서 소수점이 버려져요. `double avg`로 받는 건 이미 늦어요.

**고친 코드**: 나누기 전에 한쪽을 `double`로 바꿔요.

```c
double avg = (double)sum / n;   // 3.500000
```

`(double)sum`이 먼저 `7.0`이 되고, `n`도 자동으로 `double`로 올라가서 `7.0 / 2.0 = 3.5`가 돼요.

**주의**: `(double)(sum / n)`은 안 돼요. 괄호 안에서 먼저 정수 나눗셈이 끝나서 `3.0`이 나와요.

예측해 보세요. `double avg = (double)(sum + 1) / n;`의 출력은 뭘까요?
