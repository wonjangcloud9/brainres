리스트를 도는 중에 `remove`로 그 리스트를 바꿔서 그래요. 결과는 `[3, 2, 4]`예요.

**왜 이렇게 나오나요?**
`for`는 "몇 번째 칸"을 기억하며 앞으로 가요. 요소를 지우면 뒤 요소들이 한 칸씩 앞으로 당겨져요. 그러면 다음 요소를 건너뛰어요.

1. 0번 칸 `1`은 홀수라서 지워요. 리스트가 `[3, 5, 2, 4]`가 돼요.
2. 1번 칸으로 가요. 그 칸에는 `5`가 있어요. `3`은 한 번도 검사받지 못했어요. `5`를 지워요. 리스트가 `[3, 2, 4]`가 돼요.
3. 2번 칸 `4`는 짝수예요. 끝나요.

**고친 코드 (한 줄만 바꿔요)**

```python
nums = [1, 3, 5, 2, 4]
for n in nums[:]:      # nums[:]는 복사본이에요
    if n % 2 == 1:
        nums.remove(n)
print(nums)  # [2, 4]
```

복사본을 도니까 원본을 지워도 순회가 흔들리지 않아요.

**더 파이썬다운 방법**은 지우지 않고 짝수만 모아 새 리스트를 만드는 거예요.

```python
nums = [n for n in nums if n % 2 == 0]
```
