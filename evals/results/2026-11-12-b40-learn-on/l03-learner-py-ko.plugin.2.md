```python
nums = [1, 3, 5, 2, 4]
for n in nums:
    if n % 2 == 1:
        nums.remove(n)
print(nums)
``` -->

결과는 `[3, 2, 4]`가 나와요. 순회하는 리스트를 도중에 바꿔서, 3이 검사도 못 받고 건너뛰어졌기 때문이에요.

**과정**

`for`는 인덱스 0, 1, 2…를 차례로 봐요. 요소를 지우면 뒤 요소가 앞으로 당겨져요.

1. 인덱스 0은 `1`이고 홀수라서 지워요. 리스트는 `[3, 5, 2, 4]`가 돼요.
2. 인덱스 1을 봐야 하는데 `3`은 인덱스 0으로 밀렸어요. 그래서 `5`를 보고 지워요. 리스트는 `[3, 2, 4]`가 돼요.
3. 인덱스 2는 `4`라서 짝수예요. 끝나요.

**고친 코드 (원래 줄만 바꿔요)**

```python
for n in nums[:]:   # 복사본을 순회해요
    if n % 2 == 1:
        nums.remove(n)
```

`nums[:]`는 복사본이에요. 복사본은 그대로 있고 원본만 줄어들어서 빠지는 요소가 없어요.

더 파이썬다운 방법은 새 리스트를 만드는 거예요.

```python
nums = [n for n in nums if n % 2 == 0]
```
