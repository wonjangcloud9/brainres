내용을 바꿀 일이 있으면 리스트, 바꿀 일이 없으면 튜플을 쓰세요.

| | 리스트 `[1, 2]` | 튜플 `(1, 2)` |
|---|---|---|
| 수정 | 가능 (`append`, 값 변경) | 불가능 |
| 용도 | 같은 종류 데이터를 모은 목록 | 서로 다른 값을 묶은 한 덩어리 |
| 딕셔너리 키 | 불가 | 가능 (안의 값도 불변일 때) |

리스트는 길이가 변하는 같은 종류의 값에 써요. 예: 사용자 이름 목록 `names = ["민수", "지은"]`.

튜플은 길이가 고정된 값 묶음에 써요. 예: 좌표 `point = (37.5, 127.0)`. 실수로 값이 바뀌는 일을 막아 주고, 딕셔너리 키나 집합 원소로도 쓸 수 있어요.

튜플이 리스트보다 조금 빠르고 메모리도 적게 써요. 하지만 차이가 작아서 선택 기준은 아니에요. 의도를 코드에 드러내는 쪽이 더 중요해요.

고민될 때는 일단 리스트로 시작하세요. 나중에 "이 값은 절대 안 바뀌어야 한다"는 곳이 보이면 그때 튜플로 바꾸면 돼요.

쓰려는 데이터가 구체적이면 알려 주세요. 어느 쪽이 맞는지 같이 골라 볼게요.
