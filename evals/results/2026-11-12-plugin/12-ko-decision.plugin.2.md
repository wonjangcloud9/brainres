**내용이 바뀌면 리스트, 바뀌지 않는 고정된 묶음이면 튜플을 쓰세요.**

| | 리스트 `[]` | 튜플 `()` |
|---|---|---|
| 수정 | 가능 (`append`, `remove` 등) | **불가능** (만들면 끝) |
| 용도 | 같은 종류 값이 여러 개 | 서로 다른 값을 한 묶음으로 |
| 딕셔너리 키 | 못 씀 | 쓸 수 있음 (값이 해시 가능할 때) |
| 속도·메모리 | 약간 더 큼 | 약간 작고 빠름 |

**리스트가 맞는 경우**
```python
scores = [90, 85, 77]
scores.append(100)  # 계속 늘어나는 데이터
```

**튜플이 맞는 경우**
```python
point = (37.5, 127.0)           # 위도, 경도처럼 한 세트
grid = {(0, 0): "시작", (1, 2): "벽"}  # 좌표를 딕셔너리 키로
def min_max(xs): return min(xs), max(xs)  # 값 여러 개 반환
```

판단이 어려우면 이렇게 물어보세요. "나중에 항목을 추가하거나 바꾸나요?" 그렇다면 리스트예요. 아니고 각 자리마다 뜻이 다르다면 튜플이에요.

속도 차이는 거의 신경 쓰지 않아도 돼요. 튜플을 쓰는 진짜 이유는 "이 값은 바뀌지 않는다"를 코드로 보장하는 거예요.
