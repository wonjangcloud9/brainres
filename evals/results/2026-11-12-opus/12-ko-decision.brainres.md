<!-- Q: 파이썬에서 리스트랑 튜플 중에 뭘 써야 해? -->

**값이 바뀌면 리스트, 고정된 묶음이면 튜플을 쓰세요.**

| 기준 | 리스트 `[]` | 튜플 `()` |
|---|---|---|
| 수정 | 추가·삭제·변경 가능해요 | 만든 뒤 못 바꿔요 |
| 딕셔너리 키, 세트 원소 | 못 써요 | 쓸 수 있어요 |
| 주된 용도 | 같은 종류 값 여러 개 | 위치마다 의미가 다른 값 묶음 |
| 메모리 | 조금 더 써요 | 조금 덜 써요 |

```python
# 개수가 늘어나요 → 리스트
cart = ["사과", "우유"]
cart.append("빵")

# 자리마다 의미가 정해져 있어요 → 튜플
point = (37.5, 127.0)   # (위도, 경도)
visits = {point: 3}     # 튜플이라 키로 쓸 수 있어요
```

헷갈리면 "나중에 이 값을 바꿀까?"라고 물어보세요. 바꾼다면 리스트를 고르세요. 안 바꾼다면 튜플이 실수로 바뀌는 걸 막아 줘요.

한 가지 주의할 점이 있어요. 튜플 안에 리스트가 있으면 **키로 못 써요**. `{([1], 2): "x"}`는 `TypeError: unhashable type: 'list'`를 내요.

지금 다루는 데이터를 보여 주시면 어느 쪽이 맞는지 봐 드릴게요.
