## 핵심 기준: **데이터가 바뀌어야 하나?**

| | 리스트 `[]` | 튜플 `()` |
|---|---|---|
| 변경 가능 | ✅ (mutable) | ❌ (immutable) |
| 주 용도 | **같은 종류** 항목의 모음 | **서로 다른 의미**의 값들을 묶은 레코드 |
| 딕셔너리 키 / set 원소 | 불가 | 가능 (내부 원소도 불변일 때) |
| 성능 | 약간 무거움 | 약간 가볍고 빠름 |

## 리스트를 쓸 때
항목을 추가·삭제·정렬해야 하거나, 개수가 정해져 있지 않을 때 씁니다.

```python
scores = [90, 85, 77]
scores.append(100)
scores.sort()
```

## 튜플을 쓸 때
위치마다 의미가 정해진 고정된 묶음일 때 씁니다.

```python
point = (3, 5)                  # (x, y)
rgb = (255, 128, 0)
def get_user():
    return "철수", 25           # 여러 값 반환 → 튜플
name, age = get_user()          # 언패킹

locations = {(37.5, 127.0): "서울"}  # 딕셔너리 키로 사용
```

## 실용적인 판단법
1. **"나중에 바꿀 일이 있나?"** 있으면 리스트, 없으면 튜플을 씁니다.
2. **"각 위치가 다른 의미인가?"** 그렇다면 튜플을 씁니다. 필드가 많아지면 `namedtuple`이나 `dataclass`를 고려하세요.
   ```python
   from typing import NamedTuple
   class Point(NamedTuple):
       x: int
       y: int
   ```
3. **잘 모르겠으면 리스트**를 쓰세요. 대부분의 경우 무난합니다.

> ⚠️ 주의: 원소가 하나인 튜플은 쉼표가 꼭 필요합니다. `(1)`은 정수 1이고, `(1,)`이 튜플입니다.
