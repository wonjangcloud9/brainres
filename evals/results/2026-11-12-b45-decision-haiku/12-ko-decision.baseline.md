<!-- Q: 파이썬에서 리스트랑 튜플 중에 뭘 써야 해? -->

리스트와 튜플 중 무엇을 쓸지는 **데이터가 바뀌어야 하는지**로 판단하면 됩니다.

**리스트 (`list`)를 쓸 때**
- 원소를 추가, 삭제, 수정해야 할 때
- 같은 종류의 항목이 여러 개 쌓이는 컬렉션일 때 (예: 사용자 목록, 점수 기록)

```python
scores = [80, 90, 75]
scores.append(100)   # 추가 가능
scores[0] = 85       # 수정 가능
```

**튜플 (`tuple`)을 쓸 때**
- 값이 생성 후 변하면 안 될 때 (불변성)
- 위치마다 의미가 다른 묶음일 때 (예: 좌표 `(x, y)`, RGB `(255, 0, 0)`)
- 함수에서 여러 값을 반환할 때
- 딕셔너리의 키로 써야 할 때 (리스트는 키로 쓸 수 없고, 튜플은 가능합니다)
- 리스트보다 메모리를 적게 쓰고 약간 더 빠름

```python
point = (10, 20)
d = {(0, 0): "원점"}   # 튜플은 키로 사용 가능
```

**간단한 기준**
- "여러 개의 같은 종류 항목을 계속 다룬다" → 리스트
- "고정된 묶음, 변하면 안 되는 값" → 튜플

참고로 튜플을 쓰면 실수로 값을 바꾸는 버그를 막을 수 있어서, 변경할 필요가 없다면 튜플을 쓰는 것도 좋은 습관입니다.
