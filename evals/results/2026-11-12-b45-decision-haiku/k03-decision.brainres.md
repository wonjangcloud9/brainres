<!-- Q: 개인 프로젝트 배포할 건데 Vercel이랑 AWS 중에 뭐가 나아? -->

**개인 프로젝트라면 대부분 Vercel이 낫습니다.** Git 푸시만으로 배포되고 설정이 거의 필요 없어서, 바로 결과를 볼 수 있어요.

| 기준 | Vercel | AWS |
|---|---|---|
| 초기 설정 | GitHub 연결 후 몇 분 | IAM, VPC, 서비스 조합까지 직접 설계 |
| 잘 맞는 프로젝트 | Next.js, React, 정적 사이트, 서버리스 API | 컨테이너, 데이터베이스, 백그라운드 작업, 커스텀 인프라 |
| 비용 예측 | 트래픽이 늘면 요금이 빠르게 올라갈 수 있음 | 세밀하게 제어 가능하지만 잘못 설정하면 과금 위험 |
| 배우기 좋은 점 | 배포 자체에 집중 | 클라우드 인프라 전반을 익힘 |

AWS가 필요한 경우는 두 가지입니다. 첫째, 클라우드 자체를 공부하는 게 목표일 때요. 둘째, 장시간 실행되는 워커나 특정 AWS 서비스가 필요할 때입니다. 다만 AWS 무료 티어 기간이 끝난 뒤 예상 밖 요금이 나올 수 있으니, 예산 알림을 먼저 설정하세요. 두 서비스 모두 무료 한도와 요금 정책이 자주 바뀌므로 최신 가격은 공식 페이지에서 확인하는 게 안전합니다.

프로젝트가 어떤 스택인지(예: Next.js, Python 백엔드, DB 사용 여부) 알려주시면 더 구체적으로 골라 드리고, 필요하면 배포 설정 파일도 같이 만들어 드릴게요.
