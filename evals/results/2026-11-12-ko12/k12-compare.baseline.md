<!-- Q: 웹 개발만 하는데 맥북 에어랑 프로 중에 뭐가 나아? -->

**웹 개발만 한다면 맥북 에어를 추천해요.**

**에어가 맞는 이유**
- 웹 개발(VS Code, 브라우저, Node, Docker 정도)은 에어의 칩으로도 충분히 쾌적해요.
- 더 가볍고 휴대성이 좋아요.
- 가격이 더 저렴하고, 배터리도 오래가요.

**프로를 고려할 경우**
- 로컬에서 Docker 컨테이너를 여러 개 띄우거나 대형 모노레포를 자주 빌드할 때
- 영상 편집, 모바일 에뮬레이터 여러 개 등 무거운 작업을 병행할 때
- 외부 모니터를 여러 대 연결해야 할 때
- 밝고 선명한 디스플레이(미니 LED, 120Hz)가 중요할 때
- 장시간 고부하 작업에서도 팬이 돌아 성능이 유지되길 원할 때 (에어는 팬리스라 지속 부하에서 성능이 떨어질 수 있어요)

**팁**
칩 등급보다 **RAM이 더 중요해요.** 에어를 사더라도 **16GB 이상**(여유가 되면 24GB)을 권해요. 브라우저 탭, IDE, Docker를 같이 쓰면 8GB로는 금방 부족해져요.

정리하면, **에어 + RAM 넉넉하게**가 웹 개발에는 가성비가 제일 좋아요. 예산 범위나 주로 쓰는 스택(Docker 사용 여부 등)을 알려주시면 더 구체적으로 골라드릴게요.
