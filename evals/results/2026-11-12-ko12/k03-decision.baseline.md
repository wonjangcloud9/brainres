<!-- Q: 개인 프로젝트 배포할 건데 Vercel이랑 AWS 중에 뭐가 나아? -->

**개인 프로젝트라면 Vercel을 추천해요.**

**Vercel이 나은 경우 (대부분의 개인 프로젝트)**
- Git 연결만 하면 push할 때마다 자동 배포, PR별 프리뷰 URL 제공
- HTTPS, CDN, 도메인 연결이 설정 없이 됨
- Next.js, React, Svelte 같은 프론트엔드/풀스택 프레임워크와 궁합이 좋음
- 무료 Hobby 플랜으로 충분한 경우가 많음 (단, 비상업적 용도 한정)
- 서버 관리나 인프라 지식이 거의 필요 없음

**AWS가 나은 경우**
- 상시 실행되는 백엔드, WebSocket, 백그라운드 워커, 긴 작업이 필요할 때
- DB, 큐, 스토리지 등 여러 서비스를 직접 구성해야 할 때
- 인프라/클라우드 공부 자체가 목적일 때 (취업·자격증용 포트폴리오 등)
- 트래픽이 커져서 비용과 제어권이 중요해질 때

**주의할 점**
- AWS는 설정이 복잡하고, 잘못 설정하면 예상치 못한 요금이 나올 수 있어요. 쓴다면 Budget 알림을 꼭 걸어두세요.
- Vercel은 서버리스 함수 실행 시간 제한이 있고, 트래픽이 늘면 요금이 급격히 오를 수 있어요.
- 데이터베이스는 Vercel이 직접 호스팅하지 않으니 Neon, Supabase, PlanetScale 같은 외부 서비스와 조합하게 돼요.

**정리하면:** 웹 프론트엔드나 가벼운 풀스택 앱이면 Vercel, 인프라 경험을 쌓고 싶거나 백엔드 요구사항이 복잡하면 AWS가 맞아요. 둘 사이에서 고민이면 일단 Vercel로 시작하고, 한계가 느껴질 때 옮겨도 늦지 않아요.

프로젝트가 어떤 스택인지(프레임워크, DB 필요 여부 등) 알려주시면 더 구체적으로 골라드릴게요.
