<!-- Q: 파이썬에서 리스트랑 튜플 중에 뭘 써야 해? -->

**기본 원칙:** 바뀔 수 있는 데이터면 리스트, 바뀌지 않는 고정된 묶음이면 튜플을 쓰세요.

## 리스트 (`[]`)
- 가변(mutable): 추가, 삭제, 수정 가능
- 같은 종류의 항목을 모아둘 때 적합
- 예: 사용자 목록, 파일 이름들, 계산 결과 누적

```python
names = ["철수", "영희"]
names.append("민수")
```

## 튜플 (`()`)
- 불변(immutable): 만든 후 수정 불가
- 서로 다른 의미를 가진 값을 하나로 묶을 때 적합
- 예: 좌표 `(x, y)`, RGB `(255, 0, 0)`, 함수의 여러 반환값

```python
point = (3, 4)
def min_max(nums):
    return min(nums), max(nums)
```

## 선택 기준

| 상황 | 선택 |
|---|---|
| 길이/내용이 변함 | 리스트 |
| 고정된 값, 실수로 바뀌면 안 됨 | 튜플 |
| 딕셔너리 키나 set 원소로 써야 함 | 튜플 (해시 가능) |
| 항목마다 역할이 다름 (이름, 나이 등) | 튜플 (또는 `namedtuple`/`dataclass`) |
| 반복문으로 같은 종류 요소 처리 | 리스트 |

## 참고
- 튜플은 리스트보다 약간 가볍고 빠르지만, 성능 차이 때문에 고르는 경우는 드뭅니다. **의도를 표현하는 것**이 더 중요합니다.
- 튜플 안에 리스트 같은 가변 객체가 있으면 그 내부는 여전히 바뀔 수 있습니다.
- 요소가 하나인 튜플은 `(1,)`처럼 쉼표가 필요합니다.

고민되면 일단 리스트로 시작하고, "이건 절대 바뀌면 안 되는 값이네" 싶을 때 튜플로 바꾸면 됩니다.
