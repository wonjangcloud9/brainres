<!-- Q: 파이썬에서 리스트랑 튜플 중에 뭘 써야 해? -->

내용을 바꿀 필요가 있으면 리스트, 바뀌지 않는 고정된 묶음이면 튜플을 쓰세요.

**리스트 (`[]`)**: 항목을 추가, 삭제, 수정해야 할 때 씁니다. 같은 종류의 값이 여러 개 모인 경우가 많습니다.
```python
files = ["a.txt", "b.txt"]
files.append("c.txt")
```

**튜플 (`()`)**: 한 번 만들면 바뀌지 않는 값에 씁니다. 서로 다른 종류의 값을 하나로 묶을 때(좌표, 레코드, 함수의 여러 반환값)도 적합합니다.
```python
point = (37.5, 127.0)   # 위도, 경도
```

튜플을 고르면 좋은 이유는 세 가지입니다.
- 실수로 수정되는 것을 막아 줍니다.
- 딕셔너리 키나 set 원소로 쓸 수 있습니다(리스트는 불가).
- 메모리를 조금 덜 쓰고 약간 빠릅니다. 다만 차이는 작아서 선택 기준으로는 약합니다.

헷갈리면 일단 리스트를 쓰고, "이 값은 절대 바뀌면 안 된다"거나 딕셔너리 키로 필요할 때 튜플로 바꾸면 됩니다.
