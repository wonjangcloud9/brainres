<!-- Q: 도커랑 가상머신 차이가 뭐야? -->

핵심 차이는 **OS 커널을 공유하느냐**입니다. 가상머신(VM)은 게스트 OS 전체를 따로 띄우고, 도커 컨테이너는 호스트의 커널을 공유하면서 프로세스만 격리합니다.

| | 가상머신 | 도커 컨테이너 |
|---|---|---|
| 격리 단위 | 하드웨어 전체 (하이퍼바이저가 가상화) | 프로세스 (namespace, cgroup) |
| OS | 게스트 OS를 각자 설치 | 호스트 커널 공유 |
| 크기 | 수 GB~수십 GB | 수십 MB~수백 MB |
| 시작 시간 | 수십 초~분 | 보통 1초 내외 |
| 격리 강도 | 강함 (커널이 분리됨) | 상대적으로 약함 (커널 취약점이 공유됨) |
| 적합한 용도 | 다른 OS 실행, 강한 보안 경계 | 앱 배포, 개발 환경 통일, 마이크로서비스 |

컨테이너가 가벼운 이유는 OS를 부팅하지 않기 때문입니다. 그래서 같은 서버에 훨씬 많이 띄울 수 있습니다. 반대로 커널을 공유하기 때문에 리눅스 호스트에서 윈도우 컨테이너를 돌릴 수는 없고, 커널 수준 취약점이 있으면 컨테이너 간 격리가 뚫릴 수 있습니다.

지금 쓰시는 macOS에서는 도커 컨테이너가 리눅스 커널을 필요로 하므로, Docker Desktop이 내부적으로 작은 리눅스 VM을 하나 띄우고 그 위에서 컨테이너를 실행합니다. 즉 Mac에서는 둘이 같이 쓰이는 셈입니다.

다음으로 `docker run -it ubuntu bash`를 직접 실행해 보면 컨테이너가 얼마나 빨리 뜨는지 바로 체감할 수 있습니다.
