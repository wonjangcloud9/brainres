```bash
find . -name '*.log' -mtime +7 -print0 | xargs -0 gzip
``` -->

이 스크립트는 **7일보다 오래된 `.log` 파일을 찾아 gzip으로 압축**합니다.

## 단계별 설명

**1. `find . -name '*.log' -mtime +7 -print0`**
- `.` : 현재 디렉터리부터 하위 디렉터리까지 재귀 탐색
- `-name '*.log'` : 파일명이 `.log`로 끝나는 것만 대상 (따옴표로 셸이 glob을 먼저 확장하지 않게 함)
- `-mtime +7` : 마지막 수정 시각이 **7일보다 이전**인 파일 (정확히는 8일 이상 지난 파일. `find`는 경과 일수를 내림하므로 `+7`은 7×24시간을 초과해 8일째부터 매칭됩니다)
- `-print0` : 결과를 줄바꿈 대신 **널 문자(`\0`)**로 구분해 출력

**2. `|`**
- 앞 명령의 출력(파일 목록)을 다음 명령의 입력으로 전달

**3. `xargs -0 gzip`**
- `-0` : 입력을 널 문자로 구분해서 읽음 (`-print0`과 짝)
- 받은 파일 목록을 인자로 `gzip`을 실행

## `-print0` / `-0`를 쓰는 이유
파일명에 공백, 따옴표, 줄바꿈이 있어도 안전하게 처리하기 위해서입니다. 예를 들어 `my app.log`는 일반 방식이면 `my`와 `app.log`로 쪼개져 잘못 처리됩니다.

## 동작 결과
- `app.log` → `app.log.gz`로 바뀌고 **원본은 삭제**됩니다 (gzip 기본 동작).
- 이미 `.gz`가 있는 경우 덮어쓸지 물어보거나 실패할 수 있습니다.

## 주의점
- 현재 쓰이고 있는 로그(프로세스가 열고 있는 파일)를 압축하면 문제가 생길 수 있지만, 7일 넘게 수정되지 않았다면 대개 안전합니다.
- 실행 전에 대상을 확인하려면 gzip 부분을 빼고 먼저 실행해 보세요:
  ```bash
  find . -name '*.log' -mtime +7
  ```
- 원본을 보존하고 싶다면 `xargs -0 gzip -k` (`-k`는 keep 옵션)를 쓰면 됩니다. macOS 기본 gzip에서 `-k`가 지원되는지는 버전에 따라 다를 수 있으니 확인해 보세요.
