<!-- Q: 이 스크립트 설명해줘

```bash
find . -name '*.log' -mtime +7 -print0 | xargs -0 gzip
``` -->

이 명령은 **현재 디렉터리 아래에서 7일보다 오래된 `.log` 파일을 찾아 gzip으로 압축**합니다.

## 구성 요소별 설명

**1. `find . -name '*.log' -mtime +7 -print0`**
- `.` : 현재 디렉터리부터 하위 디렉터리까지 재귀적으로 탐색
- `-name '*.log'` : 이름이 `.log`로 끝나는 파일만 선택 (따옴표로 감싸 셸이 먼저 glob을 확장하지 않게 함)
- `-mtime +7` : 마지막 수정 시각이 **7일보다 더 이전**인 파일 (`+7`은 8일 이상 지난 파일을 의미함. find는 일 단위로 내림 계산하기 때문)
- `-print0` : 결과를 줄바꿈 대신 **널 문자(`\0`)** 로 구분해 출력

**2. `|`**
- 앞 명령의 출력을 뒤 명령의 입력으로 전달

**3. `xargs -0 gzip`**
- `-0` : 입력을 널 문자 기준으로 분리 (`-print0`과 짝을 이룸)
- 받은 파일 목록을 인자로 `gzip`에 넘겨 실행

## 왜 `-print0` / `-0`를 쓰나요?
파일명에 공백, 줄바꿈, 따옴표 등이 있어도 안전하게 처리하기 위해서입니다. 예를 들어 `my app.log`가 있어도 두 개의 파일(`my`, `app.log`)로 잘못 쪼개지지 않습니다.

## 동작 결과
- `app.log` → `app.log.gz` (원본은 삭제되고 압축본만 남음)
- 이미 `.gz`로 끝나는 파일은 `*.log` 패턴에 해당하지 않으므로 건드리지 않음

## 주의할 점
- **원본이 삭제됩니다.** 원본을 유지하려면 `gzip -k` (일부 구버전 gzip은 미지원)를 사용하세요.
- 같은 이름의 `.log.gz`가 이미 있으면 gzip이 덮어쓸지 물어보는데, 파이프 환경에서는 건너뛰거나 실패할 수 있습니다.
- 현재 **쓰고 있는 로그 파일**이 7일 넘게 수정되지 않았다면 압축될 수 있으니, 실행 중인 프로세스가 열어둔 파일은 주의하세요.
- 실행 전에 `find . -name '*.log' -mtime +7` 만 먼저 돌려 대상 목록을 확인해 보는 것을 권장합니다.
