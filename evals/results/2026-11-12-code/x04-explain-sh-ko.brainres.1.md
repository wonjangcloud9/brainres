<!-- Q: 이 스크립트 설명해줘

```bash
find . -name '*.log' -mtime +7 -print0 | xargs -0 gzip
``` -->

현재 디렉터리 아래에서 7일보다 오래전에 수정된 `.log` 파일을 찾아 각각 gzip으로 압축해요.

**각 부분의 역할**

| 부분 | 의미 |
|---|---|
| `find .` | 현재 디렉터리부터 하위 전체를 탐색해요 |
| `-name '*.log'` | 이름이 `.log`로 끝나는 파일만 골라요 (따옴표는 셸이 `*`를 먼저 해석하지 않게 막아요) |
| `-mtime +7` | 마지막 수정이 7일보다 더 전인 파일이에요. 정확히는 "8일 이상 지난" 파일이에요 |
| `-print0` | 파일 이름을 줄바꿈 대신 널 문자(`\0`)로 구분해 출력해요 |
| `xargs -0` | 널 문자로 구분된 입력을 읽어요 |
| `gzip` | 받은 파일들을 압축해요 |

**`-print0`과 `-0`을 쓰는 이유**

파일 이름에 공백이나 줄바꿈이 있어도 하나의 이름으로 안전하게 전달돼요. 이 둘을 빼면 `my app.log`가 `my`와 `app.log` 두 개로 쪼개져요.

**실행 결과**

`gzip`은 원본을 지우고 `파일명.log.gz`로 바꿔요. 즉 `app.log`는 사라지고 `app.log.gz`만 남아요. 이미 `.gz`가 있으면 덮어쓸지 물어보거나 오류가 나요.

**주의할 점**

- 하위 디렉터리까지 모두 대상이에요. 범위를 제한하려면 `-maxdepth 1`을 `.` 바로 뒤에 붙이세요.
- 실행 중인 프로그램이 쓰는 로그라면 압축 후 문제가 생길 수 있어요.
- 되돌리기는 `gunzip`으로 가능하지만, 수정 시각은 유지돼요.

먼저 대상만 확인하려면 `| xargs -0 gzip` 부분을 빼고 `-print0` 대신 `-print`로 실행해 보세요.
