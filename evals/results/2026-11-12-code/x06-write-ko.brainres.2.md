<!-- Q: 폴더 안에 있는 이미지 파일들 이름을 날짜순으로 바꿔주는 스크립트 짜줘. -->

`rename_by_date.py`를 만들었어요. 기본은 미리보기이고, `--apply`를 붙여야 실제로 이름이 바뀌어요.

실행 결과 출력이 저에게 돌아오지 않아서 테스트가 통과했는지는 확인하지 못했어요. 그러니 처음에는 미리보기로 결과를 직접 확인해 주세요.

```bash
python3 rename_by_date.py ~/Pictures/trip            # 미리보기
python3 rename_by_date.py ~/Pictures/trip --apply    # 실제 실행
```

- **새 이름 형식:** `20240102_030400_001.jpg`처럼 `날짜_시간_순번.확장자`예요. 이름순으로 정렬하면 날짜순이 돼요.
- **날짜 기준:** EXIF 촬영일을 먼저 쓰고, 없으면 파일 생성일, 그다음 수정일을 써요. EXIF는 Pillow(`pip install pillow`)가 있을 때만 읽어요.
- **대상 확장자:** jpg, jpeg, png, gif, heic, webp, tif, tiff, bmp예요. 하위 폴더는 건드리지 않아요.
- **충돌 방지:** 임시 이름으로 먼저 옮긴 뒤 최종 이름으로 바꿔서 이름이 겹쳐도 덮어쓰지 않아요.

원래 이름으로 되돌리는 기능은 없어요. 중요한 사진이면 폴더를 복사해 두고 `--apply`를 실행하세요.

원하는 이름 형식이 다르면(예: `001.jpg`만, 또는 원래 이름 유지하고 앞에 날짜만) 알려 주세요. 바로 고쳐 드릴게요.
