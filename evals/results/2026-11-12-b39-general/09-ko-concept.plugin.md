<!-- Q: 도커랑 가상머신 차이가 뭐야? -->

도커는 호스트 OS의 커널을 공유하는 격리된 프로세스이고, 가상머신은 하드웨어까지 가상화해서 OS를 통째로 따로 돌려요.

| | 도커 컨테이너 | 가상머신 |
|---|---|---|
| 격리 단위 | 프로세스 (커널 공유) | 전체 OS (커널 별도) |
| 시작 시간 | 보통 1초 안팎 | 보통 수십 초~분 |
| 크기 | 수십~수백 MB | 수 GB |
| 자원 사용 | 가벼워요 | OS마다 메모리와 CPU를 먹어요 |
| 보안 격리 | 상대적으로 약해요 | 강해요 |
| OS 선택 | 호스트와 같은 커널만 가능 | Windows, Linux 등 자유 |

**핵심 차이는 커널이에요.** VM은 하이퍼바이저 위에 게스트 OS를 올려서 각자 커널을 가져요. 컨테이너는 호스트 커널을 같이 쓰고, 파일시스템과 프로세스, 네트워크만 분리해요. 그래서 컨테이너가 훨씬 가볍고 빨라요.

대신 커널을 공유하니 컨테이너 하나가 커널 취약점에 뚫리면 호스트가 위험해질 수 있어요. 신뢰할 수 없는 코드를 돌릴 때는 VM이 더 안전해요.

참고로 맥이나 윈도우에서 도커를 쓰면 내부적으로 작은 리눅스 VM이 돌아가요. 컨테이너가 리눅스 커널을 필요로 하기 때문이에요.

**언제 뭘 쓸까요?**
- 앱 배포, 개발 환경 통일, 마이크로서비스: 도커
- 다른 OS 필요, 강한 격리, 레거시 시스템: VM
- 둘을 함께 쓰는 경우도 흔해요. 클라우드 VM 위에서 컨테이너를 돌리는 식이에요.

도커를 처음 써 보신다면 `docker run hello-world`로 시작해 보세요.
