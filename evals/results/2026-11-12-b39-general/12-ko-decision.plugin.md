<!-- Q: 파이썬에서 리스트랑 튜플 중에 뭘 써야 해? -->

**내용을 바꿀 일이 있으면 리스트, 바뀌지 않는 고정된 묶음이면 튜플을 쓰세요.**

| | 리스트 `[]` | 튜플 `()` |
|---|---|---|
| 수정(추가·삭제·변경) | 가능 | 불가능 |
| dict 키, set 원소로 사용 | 불가능 | 가능 (원소도 해시 가능할 때) |
| 주 용도 | 같은 종류 값의 모음, 길이가 변함 | 서로 다른 값의 고정된 묶음 |

```python
# 리스트: 길이가 변하는 같은 종류의 데이터
scores = [90, 85]
scores.append(77)

# 튜플: 의미가 정해진 고정 구조
point = (37.5, 127.0)           # (위도, 경도)
visited = {(0, 0): "시작"}      # 튜플은 dict 키로 쓸 수 있어요
```

- **튜플이 유리한 경우**: 함수가 값을 여러 개 반환할 때, 좌표처럼 위치마다 의미가 있을 때, 실수로 바뀌면 안 되는 상수 목록일 때
- **성능**: 튜플이 생성 속도와 메모리 면에서 약간 유리해요. 하지만 차이가 작아서, 고르는 기준은 성능이 아니라 의도예요.
- **주의**: 튜플은 안의 리스트까지 얼려 주지 않아요. `([1], 2)`의 `[1]`은 여전히 수정돼요.

고민되면 일단 리스트로 시작하고, "이 값은 절대 안 바뀐다"가 분명할 때 튜플로 바꾸세요. 쓰려는 상황을 알려 주시면 어느 쪽이 맞는지 같이 골라 볼게요.
