```python
nums = [2, 4, 6, 1]

    if n % 2 == 0:
        nums.remove(n)

`[4, 1]`이 출력돼요.

리스트를 순회하는 중에 `remove`로 요소를 지우면, 인덱스가 밀려서 일부 요소를 건너뛰어요. 순서대로 보면 이래요.

1. 인덱스 0: `n=2`는 짝수예요. 지우면 `[4, 6, 1]`이 돼요.
2. 인덱스 1: `n=6`이에요. 4가 인덱스 0으로 당겨져서 건너뛰었어요. 6은 짝수라서 지우면 `[4, 1]`이 돼요.
3. 인덱스 2: 리스트 길이가 2라서 순회가 끝나요.

결과적으로 4는 검사조차 안 돼서 짝수인데도 남아요.

짝수를 모두 지우려면 새 리스트를 만드세요.

```python
nums = [n for n in nums if n % 2 != 0]  # [1]
```
