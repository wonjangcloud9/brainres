<!-- Q: 파이썬에서 리스트랑 튜플 중에 뭘 써야 해? -->

값을 나중에 바꿀 일이 있으면 리스트, 한 번 만들고 안 바꾸면 튜플을 쓰세요.

| | 리스트 `[]` | 튜플 `()` |
|---|---|---|
| 변경 | 가능 | 불가능 |
| 딕셔너리 키, 집합 원소 | 불가능 | 가능 (내용이 전부 해시 가능할 때) |
| 용도 | 같은 종류의 값이 여러 개 | 서로 다른 값을 한 묶음으로 |

고르는 기준은 두 가지예요.

1. **데이터의 성격**: 파일 이름 목록처럼 같은 종류가 늘고 줄면 리스트예요. `(x, y)` 좌표나 `(이름, 나이)`처럼 칸마다 뜻이 다르고 길이가 고정이면 튜플이에요.
2. **실수 방지**: 튜플은 바뀔 수 없어서, 함수에 넘겨도 안에서 몰래 바뀌지 않아요. 상수 목록에도 잘 맞아요.

```python
files = ["a.txt", "b.txt"]
files.append("c.txt")        # 리스트: 추가 가능

point = (3, 4)
point[0] = 5                 # TypeError: 튜플은 수정 불가

visited = {(0, 0), (1, 2)}   # 튜플은 집합에 넣을 수 있음
```

성능 차이는 튜플이 조금 더 가볍고 빠른 정도라서(보통 무시할 수준) 선택 기준으로 삼지 않아도 돼요.

고민되면 일단 리스트로 시작하세요. "이건 절대 안 바뀐다"는 확신이 들 때 튜플로 바꾸면 돼요.
