<!-- Q: 파이썬에서 리스트랑 튜플 중에 뭘 써야 해? -->

값을 나중에 바꿀 일이 있으면 리스트, 바꾸지 않을 고정된 묶음이면 튜플을 쓰세요.

| | 리스트 `[]` | 튜플 `()` |
|---|---|---|
| 수정 | 가능 (append, 삭제 등) | 불가능 |
| 용도 | 같은 종류의 값이 늘고 줄 때 | 서로 다른 값을 한 묶음으로 고정할 때 |
| 딕셔너리 키 | 불가 | 가능 (값이 해시 가능할 때) |
| 속도·메모리 | 약간 더 큼 | 약간 작고 빠름 |

예를 들어 장바구니 상품 목록은 계속 추가하니까 리스트가 맞아요.

```python
cart = ["사과", "배"]
cart.append("귤")
```

반대로 좌표나 RGB 색상은 길이와 의미가 정해져 있으니 튜플이 맞아요.

```python
point = (37.56, 126.97)
colors = {(255, 0, 0): "빨강"}   # 튜플은 키로 쓸 수 있음
```

속도 차이는 대부분 무시해도 돼요. 그래서 "바뀌어야 하나?"만 기준으로 정하면 충분해요.

헷갈리면 일단 리스트로 시작하고, 나중에 "이건 절대 안 바뀐다"는 걸 알게 되면 튜플로 바꾸세요.
