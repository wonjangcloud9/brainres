```python
nums = [1, 3, 5, 2, 4]
for n in nums:
    if n % 2 == 1:
        nums.remove(n)
print(nums)
``` -->

결과는 `[3, 2, 4]`예요. 반복하는 도중에 리스트를 수정해서, 3이 검사를 건너뛰었기 때문이에요.

`for`는 "몇 번째 칸을 볼지"를 숫자(인덱스)로 기억해요. 칸을 지우면 뒤 원소가 앞으로 당겨지는데, 숫자는 그대로 1씩 올라가요.

| 인덱스 | 보는 값 | 동작 | 지운 뒤 리스트 |
|---|---|---|---|
| 0 | 1 | 홀수라서 삭제 | `[3, 5, 2, 4]` |
| 1 | 5 | 3이 0번으로 당겨져서 건너뜀. 5 삭제 | `[3, 2, 4]` |
| 2 | 4 | 짝수라서 유지 | `[3, 2, 4]` |

해결법은 원하는 값만 모아 새 리스트를 만드는 거예요.

```python
nums = [1, 3, 5, 2, 4]
nums = [n for n in nums if n % 2 == 0]
print(nums)  # [2, 4]
```

원본을 꼭 고쳐야 한다면 `for n in nums[:]:`처럼 복사본을 돌려도 돼요. 다만 저는 위의 리스트 컴프리헨션을 권해요. 더 짧고, 지우는 중에 칸이 밀리는 문제가 없어요.
