순회하는 중에 리스트를 바꾸면 요소를 건너뛰어요. 그래서 홀수 3이 남아서 `[3, 2, 4]`가 나와요.

`for`는 인덱스 0, 1, 2…를 차례로 봐요. 요소를 지우면 뒤 요소들이 앞으로 당겨져요.

| 단계 | 인덱스 | n | 삭제 후 nums |
|---|---|---|---|
| 1 | 0 | 1 | `[3, 5, 2, 4]` |
| 2 | 1 | 5 | `[3, 2, 4]` |
| 3 | 2 | 4 | 짝수라 그대로 |

1을 지우면 3이 인덱스 0으로 당겨져요. 다음 차례는 인덱스 1이라 3을 건너뛰어요.

**고치는 방법 (추천)**: 리스트 컴프리헨션으로 짝수만 모아 새 리스트를 만들어요.

```python
nums = [1, 3, 5, 2, 4]
nums = [n for n in nums if n % 2 == 0]
print(nums)  # [2, 4]
```

원본을 꼭 바꿔야 하면 복사본을 순회해요.

```python
for n in nums[:]:
    if n % 2 == 1:
        nums.remove(n)
```

`nums[:]`는 리스트의 복사본이에요. 순회하는 대상과 지우는 대상이 달라져서 건너뛰지 않아요.
