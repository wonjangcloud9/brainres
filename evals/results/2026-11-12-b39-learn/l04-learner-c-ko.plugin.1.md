<!-- Q: C 배우는 중이에요. 평균을 구하는데 소수점이 안 나와요.

```c
int sum = 7;
int n = 2;
double avg = sum / n;
printf("%f\n", avg);
``` -->

`sum / n`은 `int / int`라서 먼저 정수 나눗셈(7 / 2 = 3)이 되고, 그 결과 3이 `double`에 들어가서 `3.000000`이 출력돼요.

대입할 때 `double`로 바뀌지만, 나눗셈은 이미 끝난 뒤예요. 그래서 나누기 **전에** 한쪽을 `double`로 바꿔야 해요.

```c
int sum = 7;
int n = 2;
double avg = (double)sum / n;   // 7.0 / 2 → 3.5
printf("%f\n", avg);            // 3.500000
```

`(double)sum`은 `sum`을 실수로 바꾸는 캐스트예요. 한쪽이 `double`이면 C가 다른 쪽(`n`)도 자동으로 `double`로 맞춰요.

주의할 점은 캐스트 위치예요. `(double)(sum / n)`은 나눗셈 뒤에 바꾸니까 여전히 `3.000000`이에요.

소수점 자리를 줄이고 싶으면 `printf("%.2f\n", avg);`처럼 쓰면 `3.50`이 나와요. 직접 실행해서 `3.500000`이 나오는지 확인해 보세요.
