<!-- Q: 파이썬에서 리스트랑 튜플 중에 뭘 써야 해? -->

다음 기준으로 고르면 됩니다. 값을 바꿔야 하면 **리스트**, 바꾸지 않을 값 묶음이면 **튜플**을 쓰세요.

| 상황 | 추천 |
|---|---|
| 항목을 추가, 삭제, 수정해야 함 | 리스트 |
| 정해진 좌표나 RGB 값처럼 고정된 묶음 | 튜플 |
| 여러 반환값을 한 번에 돌려줌 | 튜플 |
| 딕셔너리의 키로 써야 함 | 튜플 (리스트는 키가 될 수 없음) |
| 같은 종류의 항목이 길게 이어짐 | 리스트 |

```python
point = (10, 20)        # 고정된 좌표
scores = [90, 85, 77]   # 나중에 추가/수정할 값
scores.append(100)      # 리스트만 가능
# point[0] = 5          # 튜플은 수정하면 TypeError
```

튜플은 값이 바뀌지 않는다는 점을 코드에 드러내고, 리스트보다 조금 가볍습니다. 확신이 없으면 리스트로 시작하고, 값이 바뀌면 안 된다는 요구가 생길 때 튜플로 바꾸세요.
