<!-- Q: 파이썬에서 리스트랑 튜플 중에 뭘 써야 해? -->

**기본적으로는 리스트를 쓰고, 값이 바뀌면 안 되거나 "고정된 묶음"을 표현할 때 튜플을 씁니다.**

## 리스트 (`list`) — 가변(mutable)
```python
fruits = ["사과", "바나나", "포도"]
fruits.append("딸기")   # 추가
fruits[0] = "배"        # 수정
fruits.remove("바나나") # 삭제
```
- 요소를 추가·삭제·수정할 수 있을 때
- 같은 종류의 항목이 여러 개 쌓이는 데이터 (목록, 결과 모음 등)

## 튜플 (`tuple`) — 불변(immutable)
```python
point = (3, 4)
rgb = (255, 128, 0)
```
- 생성 후 값을 바꿀 필요가 없을 때
- 서로 다른 의미의 값들을 묶은 "레코드"처럼 쓸 때 (좌표, RGB, DB 한 행 등)
- 딕셔너리의 키로 써야 할 때 (리스트는 키가 될 수 없음)
- 함수가 여러 값을 반환할 때 (사실 내부적으로 튜플)
- 불변이라 실수로 수정되는 걸 막고, 리스트보다 약간 가볍고 빠름

## 빠른 판단 기준
| 질문 | 답 | 선택 |
|---|---|---|
| 나중에 요소를 추가/삭제/수정하나? | 예 | 리스트 |
| 값이 절대 바뀌면 안 되나? | 예 | 튜플 |
| 딕셔너리 키나 `set` 원소로 쓰나? | 예 | 튜플 |
| 같은 타입 항목들의 모음인가? | 예 | 리스트 |
| 서로 다른 의미의 고정된 묶음인가? | 예 | 튜플 |

참고로 "튜플은 리스트보다 무조건 빠르다"는 식의 차이는 보통 체감하기 어려우니, 속도보다는 **의도 표현(수정 가능 여부)**을 기준으로 고르는 것이 좋습니다.
