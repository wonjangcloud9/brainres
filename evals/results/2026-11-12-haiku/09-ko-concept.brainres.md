<!-- Q: 도커랑 가상머신 차이가 뭐야? -->

핵심은 **도커는 운영체제 커널을 공유하고, 가상머신은 커널까지 따로 가진다**는 점이에요.

| 구분 | 도커(컨테이너) | 가상머신(VM) |
|---|---|---|
| 격리 단위 | 프로세스 | 하드웨어(가상 하드웨어) |
| 운영체제 | 호스트 커널 공유 | 게스트 OS 전체 설치 |
| 크기 | 수십~수백 MB | 수 GB |
| 시작 시간 | 초 단위 | 분 단위 |
| 성능 오버헤드 | 거의 없음 | 상대적으로 큼 |
| 격리 강도 | 상대적으로 약함 | 상대적으로 강함 |

예를 들어 맥에서 리눅스 컨테이너를 띄우면, 실제로는 맥이 Docker Desktop이 만든 경량 리눅스 VM 안에서 그 커널을 씁니다. 그래서 맥에서도 도커가 동작하는 것이고, 이 때문에 "도커는 VM 없이 돈다"는 말은 리눅스 호스트에서만 정확해요.

**언제 무엇을 쓰나요?**
- 도커: 앱을 같은 환경으로 배포하거나, 여러 서비스를 가볍게 띄울 때
- 가상머신: 윈도우 실행이 필요하거나, 커널을 바꾸거나, 보안 경계를 더 강하게 두어야 할 때
