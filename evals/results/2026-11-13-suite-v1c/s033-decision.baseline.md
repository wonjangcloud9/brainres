<!-- Q: 타입스크립트 써야 해요, 아니면 그냥 자바스크립트로 해도 돼요? -->

둘 다 괜찮아요. 프로젝트 성격에 따라 고르시면 됩니다.

**타입스크립트를 추천하는 경우**
- 프로젝트가 몇 주 이상 이어지거나 계속 유지보수할 예정일 때
- 여러 명이 함께 작업할 때
- API 응답, 설정값 등 데이터 구조가 복잡할 때
- 리팩터링이 잦을 것 같을 때 (타입이 안전망 역할을 해줘요)

**자바스크립트로 충분한 경우**
- 작은 스크립트, 프로토타입, 일회성 도구
- 혼자 빠르게 만들어 보는 학습용 프로젝트
- 빌드 설정 없이 바로 실행하고 싶을 때

**제 추천:** 새로 시작하는 프로젝트이고 어느 정도 규모가 있을 것 같다면 타입스크립트를 쓰세요. 초기 설정 비용은 작은데(요즘은 Node나 Vite 등에서 거의 바로 지원해요), 나중에 버그를 줄여주는 효과가 커요. 반대로 아주 작은 걸 빠르게 만드는 거라면 자바스크립트로 시작하고, 필요해질 때 `.ts`로 점진적으로 옮겨도 늦지 않아요.

어떤 프로젝트인지 알려주시면 더 구체적으로 말씀드릴게요.
