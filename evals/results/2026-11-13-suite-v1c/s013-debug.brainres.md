<!-- Q: 도커 컨테이너 띄우려는데 'port is already allocated' 에러가 나요. -->

호스트의 그 포트를 이미 다른 프로세스나 컨테이너가 쓰고 있어서 나는 에러예요. 점유한 쪽을 찾아 멈추거나, 다른 포트로 매핑하면 해결돼요.

**1. 누가 쓰는지 확인** (예: 포트 8080)

```sh
docker ps --filter "publish=8080"
lsof -i :8080
```

- `docker ps`에 나오면 다른 컨테이너가 점유 중이에요. `docker stop <컨테이너ID>`로 멈추세요.
- `lsof`에만 나오면 호스트 프로세스예요. macOS에서는 AirPlay 수신기가 5000, 7000 포트를 쓰는 경우가 흔해요.

**2. 멈춘 컨테이너가 남아 있는 경우**

`docker ps -a`로 확인하고 `docker rm <컨테이너ID>`로 지워요.

**3. 점유한 쪽을 두고 싶다면 호스트 포트만 바꾸기**

```sh
docker run -p 8081:8080 이미지명
```

`호스트포트:컨테이너포트` 순서라서 왼쪽만 바꾸면 돼요. compose를 쓰면 `ports:` 항목의 왼쪽 숫자를 수정하세요.

어떤 포트에서 에러가 났는지, 위 명령 결과가 어떻게 나오는지 알려 주시면 원인을 바로 짚어 드릴게요.
