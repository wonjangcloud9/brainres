<!-- Q: 파이썬 딕셔너리는 넣은 순서가 유지돼요? -->

네, 유지돼요. 파이썬 3.7부터는 딕셔너리가 **삽입 순서를 유지하는 것이 언어 사양으로 보장**됩니다.

- **3.6**: CPython 구현 세부사항으로 순서가 유지됐지만 공식 보장은 아니었어요.
- **3.7 이상**: 언어 사양에 포함되어 모든 구현체에서 보장됩니다.
- **3.5 이하**: 순서 보장 없음 (이때는 `collections.OrderedDict`를 썼어요).

알아둘 점:

```python
d = {"a": 1, "b": 2, "c": 3}
d["a"] = 100      # 기존 키 값 변경 → 순서 그대로
del d["b"]
d["b"] = 2        # 삭제 후 다시 추가 → 맨 뒤로 이동
print(d)          # {'a': 100, 'c': 3, 'b': 2}
```

- 기존 키의 값을 갱신해도 순서는 바뀌지 않아요.
- 삭제했다가 다시 넣으면 맨 뒤에 들어가요.
- 딕셔너리 간 `==` 비교는 순서를 무시합니다: `{"a":1,"b":2} == {"b":2,"a":1}`은 `True`.
- `OrderedDict`는 `==` 비교 시 순서도 고려하고, `move_to_end()` 같은 메서드가 있어서 그런 기능이 필요할 때만 쓰면 돼요.
