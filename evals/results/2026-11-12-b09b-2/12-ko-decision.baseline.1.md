<!-- Q: 파이썬에서 리스트랑 튜플 중에 뭘 써야 해? -->

**기본 원칙:** 내용이 바뀔 수 있으면 리스트, 고정된 묶음이면 튜플.

**리스트(`list`)를 쓰는 경우**
- 요소를 추가/삭제/수정해야 할 때
- 같은 종류의 데이터가 여러 개 모인 컬렉션 (예: 사용자 이름 목록, 점수들)
- 길이가 가변적일 때

**튜플(`tuple`)을 쓰는 경우**
- 값이 변하지 않는 고정된 구조 (예: 좌표 `(x, y)`, RGB `(255, 0, 0)`)
- 서로 다른 의미의 값을 묶을 때 (예: `("홍길동", 25, "서울")`)
- 딕셔너리 키나 set 원소로 써야 할 때 (튜플은 해시 가능, 리스트는 불가)
- 함수에서 여러 값을 반환할 때 (`return a, b`)
- 실수로 수정되는 걸 막고 싶을 때

**부가 차이**
- 튜플이 약간 더 가볍고 생성이 빠르지만, 대부분은 체감할 정도가 아님
- 문법: 리스트 `[1, 2]`, 튜플 `(1, 2)`. 요소가 하나인 튜플은 `(1,)`처럼 쉼표가 필요

**간단한 판단법**
```python
# 같은 성격의 항목이 늘어날 수 있다 → 리스트
fruits = ["apple", "banana"]
fruits.append("cherry")

# 위치마다 의미가 다른 고정 레코드 → 튜플
point = (3, 4)
```

확신이 안 서면 리스트로 시작하고, "이건 절대 안 바뀌어야 한다"는 의도를 표현하고 싶을 때 튜플로 바꾸면 됩니다.
