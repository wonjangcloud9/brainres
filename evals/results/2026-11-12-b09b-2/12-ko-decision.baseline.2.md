<!-- Q: 파이썬에서 리스트랑 튜플 중에 뭘 써야 해? -->

**기본 원칙:** 데이터가 바뀔 수 있으면 리스트, 바뀌지 않는 고정된 묶음이면 튜플을 쓰세요.

**리스트를 쓰는 경우**
- 항목을 추가/삭제/수정해야 할 때
- 같은 종류의 값을 여러 개 모아둘 때 (예: 사용자 이름 목록, 점수들)
- 길이가 가변적일 때

```python
scores = [90, 85]
scores.append(77)
```

**튜플을 쓰는 경우**
- 값이 바뀌지 않아야 할 때 (좌표, RGB 색상, 설정값)
- 서로 다른 종류의 값을 하나의 레코드로 묶을 때 (예: `("Kim", 25, "Seoul")`)
- 딕셔너리 키나 set 원소로 써야 할 때 (튜플은 해시 가능, 리스트는 불가)
- 함수에서 여러 값을 반환할 때

```python
point = (3, 4)
def min_max(xs):
    return min(xs), max(xs)
```

**추가 참고**
- 튜플은 리스트보다 메모리를 약간 적게 쓰고 생성도 조금 빠르지만, 대부분의 경우 성능 차이는 무시할 만합니다. 성능보다는 **의도를 표현**하는 기준으로 고르는 게 좋습니다.
- 튜플은 불변이라 "이 데이터는 바뀌지 않는다"는 신호를 코드 읽는 사람에게 줍니다.
- 단, 튜플 안에 리스트 같은 가변 객체가 있으면 그 내부는 바뀔 수 있습니다.
- 원소가 하나인 튜플은 `(1,)`처럼 쉼표가 필요합니다.

헷갈리면 일단 리스트를 쓰고, "이건 절대 안 바뀐다"는 확신이 들 때 튜플로 바꾸면 됩니다.
