<!-- Q: 도커랑 가상머신 차이가 뭐야? -->

**핵심 차이: 무엇을 가상화하느냐**

- **가상머신(VM)**: 하드웨어를 가상화합니다. 하이퍼바이저(VMware, VirtualBox, KVM 등) 위에 게스트 OS 전체(커널 포함)를 통째로 올립니다.
- **도커(컨테이너)**: OS를 가상화합니다. 호스트의 커널을 공유하고, 프로세스를 격리(namespace, cgroup)해서 따로 도는 것처럼 보이게 합니다.

**비교**

| | 가상머신 | 도커 컨테이너 |
|---|---|---|
| 커널 | VM마다 별도 | 호스트와 공유 |
| 크기 | 수 GB ~ 수십 GB | 수십 MB ~ 수백 MB |
| 시작 시간 | 수십 초 ~ 분 | 거의 즉시 (초 단위 이하) |
| 자원 사용 | 무거움 (OS마다 메모리/CPU 점유) | 가벼움 |
| 격리 수준 | 강함 (커널까지 분리) | 상대적으로 약함 (커널 공유) |
| 다른 OS 실행 | 가능 (Linux 호스트에서 Windows 등) | 호스트 커널 종류에 의존 (Linux 컨테이너는 Linux 커널 필요) |

**언제 뭘 쓰나**

- **도커**: 앱 배포, 개발 환경 통일("내 컴퓨터에선 되는데" 방지), 마이크로서비스, CI/CD처럼 가볍고 빠르게 띄우고 지우는 용도.
- **VM**: 완전히 다른 OS가 필요할 때, 강한 보안 격리가 필요할 때(멀티테넌트 등), 커널 레벨 작업이 필요할 때.

**참고: Mac에서는?**
macOS에서 도커를 쓰면 내부적으로 경량 Linux VM을 하나 띄우고 그 안에서 컨테이너가 돌아갑니다. Linux 커널이 필요하기 때문인데, 그래서 Linux에서보다 약간 오버헤드가 있습니다.

둘은 배타적이지 않아서, 클라우드에서는 VM 위에 도커 컨테이너를 올려 쓰는 구성이 흔합니다.
