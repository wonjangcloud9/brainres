nums = [2, 4, 6, 1]

    if n % 2 == 0:

`[4, 1]`이 출력돼요. 순회 중에 리스트를 수정하면 요소를 건너뛰기 때문이에요.

1. 인덱스 0: `n=2`는 짝수라서 제거해요. 리스트는 `[4, 6, 1]`이 돼요.
2. 인덱스 1: 요소가 한 칸씩 당겨져서 `4`를 건너뛰고 `n=6`을 봐요. 6도 짝수라서 제거해요. 리스트는 `[4, 1]`이 돼요.
3. 인덱스 2: 길이가 2라서 순회가 끝나요.

그래서 짝수인 `4`가 남아요.

짝수를 모두 지우려면 새 리스트를 만드는 방식이 안전해요.

```python
nums = [n for n in nums if n % 2 != 0]  # [1]
```
