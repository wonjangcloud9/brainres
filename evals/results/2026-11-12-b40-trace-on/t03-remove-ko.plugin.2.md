```python
nums = [2, 4, 6, 1]
for n in nums:
    if n % 2 == 0:
        nums.remove(n)

``` -->

`[2, 4, 6, 1]`에서 순회 중에 짝수를 지우면 `4`를 건너뛰어서 **`[4, 1]`**이 출력돼요.

1. 인덱스 0: `n=2`는 짝수라서 지워요. 리스트는 `[4, 6, 1]`이 돼요.
2. 인덱스 1: 원소들이 앞으로 당겨져서 `n=6`이 나와요. `4`는 검사하지 못하고 넘어가요. `6`을 지우면 `[4, 1]`이 돼요.
3. 인덱스 2: 길이가 2라서 반복이 끝나요.

`for`는 인덱스로 리스트를 읽어요. 그래서 순회 중에 지우면 다음 원소가 한 칸 앞으로 와서 건너뛰어져요.

모든 짝수를 지우려면 새 리스트를 만들어요.

```python
nums = [n for n in nums if n % 2 != 0]  # [1]
```
