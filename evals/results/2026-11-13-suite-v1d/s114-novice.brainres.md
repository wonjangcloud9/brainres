<!-- Q: 코딩 처음 배우는데 변수가 뭐예요? -->

변수는 값을 담아두는 이름 붙은 상자예요.

예를 들어 파이썬에서 이렇게 써요.

```python
age = 20
name = "민수"
```

- `age`라는 상자에 숫자 `20`을 넣었어요.
- `name`이라는 상자에 글자 `"민수"`를 넣었어요.

상자에 이름을 붙여두면, 값이 필요할 때 이름만 불러서 쓸 수 있어요.

```python
print(age)        # 20이 출력돼요
age = 21          # 상자 안의 값을 바꿔요
print(age)        # 21이 출력돼요
```

이름이 "변수"인 이유는 값이 **바뀔 수 있기** 때문이에요. 위에서 `age`는 20이었다가 21로 바뀌었어요.

`=`는 수학의 "같다"가 아니라 "오른쪽 값을 왼쪽 상자에 넣어라"라는 뜻이에요.
