**변수(variable)**는 데이터를 담아두는 **이름 붙은 상자**라고 생각하면 돼요.

## 비유로 이해하기

이삿짐 상자에 "주방용품"이라고 라벨을 붙여두면, 나중에 그 이름만 보고 안에 뭐가 들었는지 알 수 있죠. 변수도 똑같아요. 값에 이름을 붙여서 저장해두고, 필요할 때 이름으로 꺼내 쓰는 거예요.

## 예시 (Python)

```python
name = "민수"
age = 20

print(name)  # 민수
print(age)   # 20
```

- `name`, `age`: 변수의 **이름**
- `=`: 오른쪽 값을 왼쪽 변수에 **넣는다**는 뜻 (수학의 "같다"가 아니에요!)
- `"민수"`, `20`: 변수에 담긴 **값**

## 값은 바꿀 수 있어요

"변수(變數)"는 말 그대로 **변하는 수**예요.

```python
age = 20
age = 21      # 값을 새로 덮어씀
print(age)    # 21
```

## 계산에도 쓸 수 있어요

```python
price = 3000
count = 4
total = price * count
print(total)  # 12000
```

가격이 바뀌면 `price` 값만 고치면 되니까 편리해요.

## 변수 이름 짓기 팁

- 의미가 드러나게 짓기: `x`보다 `age`, `price`가 좋아요
- 숫자로 시작하면 안 돼요 (`1st` ❌, `first` ✅)
- 공백은 쓸 수 없어요 (`user name` ❌, `user_name` ✅)

## 정리

| 개념 | 설명 |
|---|---|
| 변수 | 값을 저장하는 이름 붙은 공간 |
| 할당(`=`) | 변수에 값을 넣는 것 |
| 값 | 변수 안에 들어있는 데이터 |
