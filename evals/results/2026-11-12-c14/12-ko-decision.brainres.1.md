<!-- Q: 파이썬에서 리스트랑 튜플 중에 뭘 써야 해? -->

**내용을 바꿀 일이 있으면 리스트, 고정된 값 묶음이면 튜플을 쓰세요.**

| | 리스트 `[]` | 튜플 `()` |
|---|---|---|
| 수정 | 가능 (append, remove 등) | 불가 |
| 용도 | 같은 종류의 값이 늘고 줄 때 | 서로 다른 값을 하나로 묶을 때 |
| 딕셔너리 키 | 불가 | 가능 (값이 해시 가능할 때) |
| 메모리 | 조금 더 큼 | 조금 더 작음 |

예를 들어 파일 목록처럼 개수가 바뀌는 데이터는 리스트가 맞아요.

```python
files = ["a.txt", "b.txt"]
files.append("c.txt")
```

좌표나 RGB처럼 길이와 의미가 고정된 데이터는 튜플이 맞아요.

```python
point = (37.5, 127.0)
color = (255, 128, 0)
visited = {(0, 0), (0, 1)}  # 튜플은 set 원소나 dict 키로 쓸 수 있어요
```

고르기 어려우면 "나중에 요소를 추가하거나 바꾸나?"를 먼저 물어보세요. 그렇다면 리스트예요. 아니라면 튜플을 쓰면 실수로 값을 바꾸는 버그를 막아 줘요.

속도 차이는 대부분 무시해도 돼요. 튜플이 약간 빠르지만, 선택 기준은 속도가 아니라 의미예요.
