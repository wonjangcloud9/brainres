<!-- Q: 도커랑 가상머신 차이가 뭐야? -->

가장 큰 차이는 OS 커널을 따로 두느냐 공유하느냐예요. 가상머신(VM)은 가상 하드웨어 위에 OS를 통째로 하나 더 올려요. 도커 컨테이너는 호스트의 커널을 같이 쓰고, 프로세스만 격리해요.

| 항목 | 가상머신 | 도커 컨테이너 |
|---|---|---|
| 격리 단위 | OS 전체 | 프로세스와 파일 환경 |
| 커널 | VM마다 따로 | 호스트와 공유 |
| 크기 | 보통 수 GB | 보통 수십~수백 MB |
| 시작 시간 | 수십 초~분 | 보통 1초 안팎 |
| 격리 강도 | 강함 | 상대적으로 약함 |

커널을 공유하기 때문에 컨테이너가 가볍고 빨라요. 같은 이유로 격리는 VM보다 약해요. 커널 취약점이 있으면 컨테이너 사이로 영향이 퍼질 수 있어요.

용도도 달라요. 도커는 "내 PC에서는 되는데 서버에선 안 돼요" 같은 환경 차이를 줄이는 데 좋아요. VM은 Windows 위에 Linux를 돌리는 것처럼 다른 OS가 필요할 때, 또는 강한 격리가 필요할 때 써요.

지금 쓰시는 Mac에서는 이 둘이 겹쳐요. 컨테이너는 리눅스 커널이 필요한데 macOS 커널은 다르거든요. 그래서 Docker Desktop은 내부에서 작은 리눅스 VM을 하나 띄우고, 그 안에서 컨테이너를 실행해요.

직접 확인하려면 터미널에서 `docker run hello-world`를 실행해 보세요. 컨테이너가 얼마나 빨리 뜨는지 바로 보여요.
