<!-- Q: 클로저가 뭐예요? -->

클로저는 함수가 자신이 만들어진 곳의 변수를 기억해서, 그 바깥 범위가 끝난 뒤에도 쓸 수 있게 하는 기능이에요.

자바스크립트, 파이썬, 스위프트 같은 언어에서 쓰여요. 콜백, 이벤트 핸들러, 값을 숨기는 모듈에서 자주 보여요.

```js
function makeCounter() {
  let count = 0;          // 바깥 함수의 변수
  return function () {    // 이 안쪽 함수가 클로저예요
    count += 1;
    return count;
  };
}

const counter = makeCounter();
counter(); // 1
counter(); // 2
```

`makeCounter()`는 이미 끝났지만, 안쪽 함수가 `count`를 계속 기억해요. 그래서 호출할 때마다 값이 이어져요. 바깥에서는 `count`를 직접 건드릴 수 없어서, 값을 안전하게 숨기는 용도로도 써요.

참고로 "Clojure"라는 프로그래밍 언어도 한글로 클로저라고 불러요. 그 언어를 물으신 거라면 말씀해 주세요.
