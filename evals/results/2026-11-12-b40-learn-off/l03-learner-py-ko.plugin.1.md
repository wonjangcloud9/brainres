순회하는 리스트를 도중에 바꿔서 그래요. 결과는 `[3, 2, 4]`가 나오고, 홀수 3이 남아요.

**왜 이렇게 되나요?** `for`는 인덱스 번호로 리스트를 따라가요. 요소를 지우면 뒤 요소가 한 칸씩 앞으로 당겨지는데, 인덱스는 그대로 올라가요. 그래서 하나를 건너뛰어요.

| 인덱스 | n | 동작 | nums |
|---|---|---|---|
| 0 | 1 | 삭제 | `[3, 5, 2, 4]` |
| 1 | 5 | 삭제 (3은 건너뜀) | `[3, 2, 4]` |
| 2 | 4 | 짝수라 통과 | `[3, 2, 4]` |

**해결 방법 두 가지예요.**

1. 남길 것만 모아서 새 리스트를 만들어요. 가장 권장해요.
```python
nums = [n for n in nums if n % 2 == 0]
```

2. 복사본을 순회해요.
```python
for n in nums[:]:
    if n % 2 == 1:
        nums.remove(n)
```

둘 다 `[2, 4]`가 나와요. 먼저 1번으로 바꿔서 실행해 보세요.
