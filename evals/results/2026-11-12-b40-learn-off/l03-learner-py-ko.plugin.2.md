순회하는 도중에 리스트를 수정해서 그래요. 결과는 `[3, 2, 4]`이고, 3이 남아요.

**왜 그런가요?** `for`는 인덱스 번호로 리스트를 읽어요. 원소를 지우면 뒤 원소들이 앞으로 당겨지는데, 인덱스는 그대로 한 칸 앞으로 가요. 그래서 하나를 건너뛰어요.

1. 인덱스 0: `1`이 홀수라서 지워요. 리스트는 `[3, 5, 2, 4]`가 돼요.
2. 인덱스 1: 이제 `5`를 봐요. `3`은 검사도 못 하고 건너뛰어요. `5`를 지워요. 리스트는 `[3, 2, 4]`가 돼요.
3. 인덱스 2: `4`는 짝수라서 그대로 두고 끝나요.

**고치는 방법**은 두 가지예요.

```python
# 1. 짝수만 모아서 새 리스트 만들기 (추천)
nums = [1, 3, 5, 2, 4]
nums = [n for n in nums if n % 2 == 0]
print(nums)  # [2, 4]

# 2. 복사본을 순회하면서 원본에서 지우기
nums = [1, 3, 5, 2, 4]
for n in nums[:]:
    if n % 2 == 1:
        nums.remove(n)
print(nums)  # [2, 4]
```

1번이 더 짧고 빨라요. `remove`는 매번 앞에서부터 값을 찾기 때문이에요. 위 코드를 직접 돌려서 `[2, 4]`가 나오는지 확인해 보세요.
