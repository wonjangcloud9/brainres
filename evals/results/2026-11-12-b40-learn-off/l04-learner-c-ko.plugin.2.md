<!-- Q: C 배우는 중이에요. 평균을 구하는데 소수점이 안 나와요.

```c
int sum = 7;
int n = 2;
double avg = sum / n;
printf("%f\n", avg);
``` -->

`sum / n`은 `int`끼리 나눠서 `7 / 2 = 3`이 먼저 나오고, 그 3이 `3.000000`으로 바뀌어 저장돼요.

`double`에 담는 건 나눗셈이 끝난 **뒤**라서, 이미 소수점이 사라진 상태예요. 나누기 전에 한쪽을 `double`로 바꿔야 해요.

```c
double avg = (double)sum / n;   // 7.0 / 2 → 3.5
printf("%f\n", avg);            // 3.500000
```

`(double)sum`이 `sum`을 7.0으로 바꾸면, `n`도 자동으로 `double`로 맞춰져서 실수 나눗셈이 돼요. `sum / (double)n`이나 `sum / 2.0`도 똑같이 동작해요.

주의할 점은 `(double)(sum / n)`처럼 괄호를 나눗셈 전체에 씌우면 안 된다는 거예요. 이미 `3`이 나온 뒤에 바꾸는 거라 결과가 `3.000000`으로 그대로예요.

위 코드로 바꿔서 `3.500000`이 나오는지 확인해 보세요.
