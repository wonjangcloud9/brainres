<!-- Q: C 배우는 중이에요. 평균을 구하는데 소수점이 안 나와요.

```c
int sum = 7;
int n = 2;
double avg = sum / n;
printf("%f\n", avg);
``` -->

`sum / n`이 `int / int`라서 먼저 정수 나눗셈(`7 / 2 = 3`)이 되고, 그 결과 `3`이 `double`에 들어가 `3.000000`이 출력돼요.

`double`에 담는 것은 나눗셈이 끝난 **뒤**의 일이라 소용이 없어요. 나누기 전에 피연산자 하나를 `double`로 바꿔야 해요.

```c
double avg = (double)sum / n;   // 3.500000
```

`(double)sum`이 `7.0`이 되고, `n`도 자동으로 `2.0`으로 바뀌어서 실수 나눗셈이 돼요. `sum / (double)n`이나 `sum / 2.0`도 같은 결과예요.

주의할 점은 괄호 위치예요. `(double)(sum / n)`은 나눗셈을 먼저 해서 여전히 `3.000000`이에요.

소수점 자리를 줄이려면 `printf("%.1f\n", avg);`처럼 쓰면 돼요. 다음으로 `(double)sum / n`으로 바꿔서 `3.500000`이 나오는지 확인해 보세요.
