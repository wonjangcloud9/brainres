<!-- Q: 도커랑 가상머신 차이가 뭐야? -->

핵심 차이는 커널을 공유하느냐예요. 도커 컨테이너는 호스트 OS의 커널을 같이 쓰고, 가상머신(VM)은 게스트 OS를 통째로 따로 돌려요.

| 항목 | 도커 컨테이너 | 가상머신 |
|---|---|---|
| 격리 단위 | 프로세스 (namespace, cgroup) | 하드웨어 전체 (하이퍼바이저) |
| 커널 | 호스트와 공유 | VM마다 별도 |
| 이미지 크기 | 수십 MB ~ 수백 MB | 수 GB |
| 시작 시간 | 1초 안팎 | 수십 초 ~ 분 |
| 격리 강도 | 상대적으로 약함 | 강함 |
| 다른 OS 실행 | 불가 (Linux 컨테이너는 Linux 커널 필요) | 가능 |

**컨테이너는 커널을 공유해서** 가볍고 빨라요. 반면 커널 취약점이 생기면 호스트까지 영향을 줄 수 있어요. VM은 OS를 하나 더 올리니 무겁지만, 격리가 더 단단해요.

지금 쓰시는 Mac에서는 한 가지 더 알아두세요. macOS는 Linux 커널이 아니라서, Docker Desktop이 내부에 작은 Linux VM을 띄우고 그 안에서 컨테이너를 돌려요. 그래서 Mac에서는 도커도 VM 위에서 도는 셈이에요.

**언제 뭘 쓸까요?**
1. 앱 배포, 개발 환경 통일, 마이크로서비스: 도커
2. Windows나 다른 OS가 필요할 때: VM
3. 서로 신뢰할 수 없는 사용자의 코드를 돌릴 때: VM

다음으로는 `docker run -it ubuntu bash`를 실행해서 컨테이너가 얼마나 빨리 뜨는지 직접 확인해 보세요.
