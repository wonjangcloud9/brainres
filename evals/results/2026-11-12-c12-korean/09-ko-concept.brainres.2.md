<!-- Q: 도커랑 가상머신 차이가 뭐야? -->

가상머신(VM)은 컴퓨터 한 대를 통째로 흉내 내고, 도커 컨테이너는 호스트 OS 커널을 공유하면서 프로세스만 격리해요.

| 항목 | 가상머신 | 도커 컨테이너 |
|---|---|---|
| 격리 단위 | 하드웨어 전체 (게스트 OS 포함) | 프로세스, 파일시스템, 네트워크 |
| 커널 | VM마다 따로 가져요 | 호스트 커널을 같이 써요 |
| 크기 | 수 GB | 수십~수백 MB |
| 시작 시간 | 수십 초~분 | 1초 안팎 |
| 격리 강도 | 강해요 | 상대적으로 약해요 |

**커널을 공유하기 때문에** 컨테이너는 가볍고 빠르지만, 커널 취약점이 생기면 호스트까지 영향을 줄 수 있어요. VM은 하이퍼바이저가 중간에서 막아 주니 더 안전해요. 대신 OS를 통째로 돌려서 자원을 더 써요.

예를 들어 맥에서 리눅스용 도커 이미지를 돌리면, Docker Desktop이 내부에 작은 리눅스 VM을 띄우고 그 안에서 컨테이너를 실행해요. 컨테이너는 리눅스 커널이 필요한데 macOS 커널은 다르기 때문이에요.

선택 기준은 이래요.
- **도커**: 같은 앱 환경을 빠르게 배포하고 복제할 때
- **VM**: 다른 OS가 필요하거나, 강한 격리가 필요할 때

다음으로, 직접 `docker run -it ubuntu bash`를 실행해서 컨테이너 안을 살펴보면 차이가 바로 느껴져요.
