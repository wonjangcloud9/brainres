<!-- Q: 파이썬에서 리스트랑 튜플 중에 뭘 써야 해? -->

값이 나중에 바뀌면 리스트, 바뀌지 않으면 튜플을 쓰세요.

**리스트**는 크기와 내용을 바꿀 수 있어요. 같은 종류의 항목을 모아 두고 추가하거나 삭제할 때 맞아요.

```python
scores = [80, 95]
scores.append(70)   # 가능
```

**튜플**은 만든 뒤 바꿀 수 없어요. 서로 다른 의미의 값을 한 묶음으로 다루거나, 값이 고정이라는 점을 코드로 보여 주고 싶을 때 맞아요.

```python
point = (37.5, 127.0)   # (위도, 경도)
point[0] = 38           # TypeError
```

| 상황 | 선택 |
|---|---|
| 항목을 추가·삭제·정렬함 | 리스트 |
| 좌표, RGB처럼 길이와 의미가 고정됨 | 튜플 |
| 딕셔너리 키나 set 원소로 써야 함 | 튜플 (리스트는 해시 불가) |
| 함수가 값 여러 개를 반환함 | 튜플 |

성능 차이는 작아요. 튜플이 메모리를 조금 덜 쓰고 생성이 약간 빠르지만, 선택 기준은 속도가 아니라 의도예요.

헷갈리면 일단 리스트로 시작하고, 나중에 값이 절대 안 바뀐다는 게 분명해지면 튜플로 바꾸세요.
