<!-- Q: C 배우는 중이에요. 평균을 구하는데 소수점이 안 나와요.

```c
int sum = 7;
int n = 2;
double avg = sum / n;
printf("%f\n", avg);
``` -->

`sum / n`이 `int / int`라서 C가 정수 나눗셈(7 / 2 = 3)을 먼저 하고, 그 결과 3을 `double`에 넣기 때문에 `3.000000`이 나와요.

대입할 때 `double`로 바뀌는 건 이미 나눗셈이 끝난 뒤예요. 나눗셈 전에 피연산자 하나를 `double`로 바꿔야 해요.

```c
int sum = 7;
int n = 2;
double avg = (double)sum / n;   // 7.0 / 2 = 3.5
printf("%f\n", avg);            // 3.500000
```

`(double)sum`은 `sum` 값을 실수로 바꾸는 형변환이에요. 한쪽이 `double`이면 다른 쪽(`n`)도 자동으로 `double`이 되어 실수 나눗셈이 돼요.

**주의:** `(double)(sum / n)`은 안 돼요. 괄호 안에서 정수 나눗셈이 먼저 일어나서 여전히 `3.000000`이에요.

`sum / 2.0`처럼 리터럴을 실수로 써도 같은 효과가 있어요. 변수끼리 나눌 때는 형변환을 쓰세요.
