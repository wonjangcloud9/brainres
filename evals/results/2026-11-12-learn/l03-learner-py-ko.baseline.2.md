```python
nums = [1, 3, 5, 2, 4]

    if n % 2 == 1:

결과는 `[3, 2, 4]`가 나옵니다. 기대했던 `[2, 4]`와 다르죠.

## 원인

리스트를 순회(`for n in nums`)하는 도중에 그 리스트를 수정했기 때문입니다. `for` 루프는 내부적으로 "현재 인덱스"를 하나씩 증가시키며 진행하는데, 요소를 지우면 뒤의 요소들이 앞으로 당겨져서 일부 요소를 건너뛰게 됩니다.

실행 과정을 따라가 보면:

| 단계 | 인덱스 | nums 상태 | n | 동작 |
|---|---|---|---|---|
| 1 | 0 | `[1, 3, 5, 2, 4]` | 1 | 홀수 → 삭제 |
| 2 | 1 | `[3, 5, 2, 4]` | 5 | 홀수 → 삭제 (3은 건너뜀!) |
| 3 | 2 | `[3, 2, 4]` | 4 | 짝수 → 유지 |

1을 지운 순간 3이 인덱스 0으로 당겨졌는데, 루프는 인덱스 1로 넘어가 버려서 3을 검사하지 못했습니다.

## 해결 방법

**1. 리스트 컴프리헨션 (가장 추천)**
```python
nums = [n for n in nums if n % 2 == 0]
```

**2. 복사본을 순회하기**
```python
for n in nums[:]:      # 슬라이스로 복사본 생성
    if n % 2 == 1:
        nums.remove(n)
```

**3. `filter` 사용**
```python
nums = list(filter(lambda n: n % 2 == 0, nums))
```

보통은 1번이 가장 읽기 쉽고 파이썬답습니다. 원본 리스트 객체를 그대로 유지해야 할 때(다른 곳에서 같은 리스트를 참조 중일 때)만 2번이나 `nums[:] = [n for n in nums if n % 2 == 0]` 같은 방식을 쓰면 됩니다.
