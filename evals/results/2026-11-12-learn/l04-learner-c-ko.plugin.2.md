<!-- Q: C 배우는 중이에요. 평균을 구하는데 소수점이 안 나와요.

```c
int sum = 7;
int n = 2;
double avg = sum / n;
printf("%f\n", avg);
``` -->

`sum / n`이 `int / int`라서 먼저 정수 나눗셈(7 / 2 = 3)이 되고, 그 결과 3이 `double`에 담겨 `3.000000`이 출력돼요.

대입할 때 `double`로 바뀌지만, 그 전에 이미 소수점이 버려진 상태예요. 나누기 전에 한쪽을 `double`로 바꾸면 해결돼요.

```c
int sum = 7;
int n = 2;
double avg = (double)sum / n;   // 7.0 / 2 → 3.5
printf("%f\n", avg);            // 3.500000
```

- `(double)sum`은 `sum`을 실수로 바꾸는 형변환이에요. 한쪽이 실수면 `n`도 자동으로 실수가 돼서 실수 나눗셈이 돼요.
- `(double)(sum / n)`처럼 괄호를 나누기 바깥에 두면 안 돼요. 정수 나눗셈을 먼저 하고 나서 변환하니까 똑같이 3.0이 나와요.
- 소수점 자리를 줄이고 싶으면 `%.2f`를 쓰면 `3.50`으로 출력돼요.

직접 컴파일해서 `(double)` 위치를 바꿔 가며 결과를 비교해 보세요.
