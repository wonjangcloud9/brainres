리스트를 순회하는 도중에 그 리스트를 수정해서 요소를 건너뛰기 때문이에요. 실제 결과는 `[3, 2, 4]`이고, 홀수 `3`이 남아요.

**실행 과정**

파이썬은 "지금 몇 번째 칸을 볼지"를 인덱스로 기억해요. 요소를 지우면 뒤 요소가 한 칸씩 앞으로 당겨지는데, 인덱스는 그대로 올라가요.

1. 인덱스 0: `n=1` → 삭제 → `[3, 5, 2, 4]`
2. 인덱스 1: `n=5` (`3`은 인덱스 0으로 당겨져서 건너뜀) → 삭제 → `[3, 2, 4]`
3. 인덱스 2: `n=4` → 짝수라 유지
4. 인덱스 3: 범위 밖이라 종료

**해결 방법 1: 리스트 컴프리헨션 (권장)**

```python
nums = [1, 3, 5, 2, 4]
nums = [n for n in nums if n % 2 == 0]
print(nums)  # [2, 4]
```

**해결 방법 2: 복사본을 순회**

```python
nums = [1, 3, 5, 2, 4]
for n in nums[:]:   # 복사본을 돌고, 원본에서 삭제
    if n % 2 == 1:
        nums.remove(n)
print(nums)  # [2, 4]
```

보통은 방법 1이 짧고 빨라요. 원본 리스트 객체를 꼭 유지해야 할 때만 방법 2를 쓰세요. 두 방법을 직접 돌려 보고, `for n in nums:` 안에서 `print(n, nums)`를 찍어서 건너뛰는 순간도 확인해 보세요.
