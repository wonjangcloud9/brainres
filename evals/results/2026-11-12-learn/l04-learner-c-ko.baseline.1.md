<!-- Q: C 배우는 중이에요. 평균을 구하는데 소수점이 안 나와요.

```c
int sum = 7;
int n = 2;
double avg = sum / n;
printf("%f\n", avg);
``` -->

원인은 **정수 나눗셈**이에요. `sum`과 `n`이 둘 다 `int`라서 `sum / n`이 먼저 정수끼리 계산되어 `3`이 되고(소수점 버림), 그 결과가 `double`에 저장될 때 `3.000000`이 됩니다. 왼쪽이 `double`이어도 오른쪽 계산 방식에는 영향을 주지 않아요.

**해결 방법: 나눗셈 전에 하나를 `double`로 바꾸기**

```c
double avg = (double)sum / n;   // 캐스팅 (가장 흔한 방법)
```

또는

```c
double avg = sum / (double)n;
double avg = sum / 2.0;         // 리터럴이 상수일 때
```

결과: `3.500000`

**주의할 점**

```c
double avg = (double)(sum / n);  // ❌ 이미 정수 나눗셈 후 캐스팅이라 3.0
```

괄호 위치를 잘못 잡으면 똑같이 `3.000000`이 나와요. 캐스팅은 **나누기 전에** 피연산자에 적용해야 합니다.

소수점 자릿수를 조절하고 싶다면 `printf("%.2f\n", avg);`처럼 쓰면 `3.50`으로 출력됩니다.
