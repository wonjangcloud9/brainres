<!-- Q: C 배우는 중이에요. 평균을 구하는데 소수점이 안 나와요.

```c
int sum = 7;
int n = 2;
double avg = sum / n;
printf("%f\n", avg);
``` -->

`sum / n`이 `int / int`라서 먼저 정수 나눗셈(7 / 2 = 3)이 되고, 그 결과 3이 `double`에 담겨 `3.000000`이 출력돼요.

대입하기 전에 한쪽을 `double`로 바꾸면 해결돼요.

```c
double avg = (double)sum / n;   // 3.500000
```

`(double)sum`이 먼저 적용되어 `double / int`가 되고, `n`도 자동으로 `double`로 바뀌어 실수 나눗셈이 돼요.

주의할 점은 괄호 위치예요. `(double)(sum / n)`은 정수 나눗셈을 먼저 해서 여전히 `3.000000`이에요.

다음으로 위 한 줄로 바꿔서 `3.500000`이 나오는지 확인해 보세요.
