<!-- Q: C 배우는 중이에요. 평균을 구하는데 소수점이 안 나와요.

```c
int sum = 7;
int n = 2;
double avg = sum / n;
printf("%f\n", avg);
``` -->

`sum / n`이 `int / int`라서 먼저 정수 나눗셈(7 / 2 = 3)이 되고, 그 결과 3이 `double`로 바뀌어 `3.000000`이 출력돼요.

대입할 때 `double`로 바뀌는 건 나눗셈이 끝난 뒤예요. 그래서 나눗셈 전에 피연산자 하나를 `double`로 바꿔야 해요.

```c
double avg = (double)sum / n;   // 3.500000
```

- `(double)sum`은 `sum`을 먼저 `7.0`으로 바꿔요.
- 한쪽이 `double`이면 `n`도 자동으로 `double`이 돼서 `7.0 / 2.0 = 3.5`가 돼요.
- `7.0 / 2`처럼 상수에 `.0`을 붙여도 같은 효과예요.

주의할 점은 괄호 위치예요. `(double)(sum / n)`은 정수 나눗셈을 먼저 하므로 여전히 `3.0`이에요.

위 한 줄로 고쳐서 `3.500000`이 나오는지 확인해 보세요.
