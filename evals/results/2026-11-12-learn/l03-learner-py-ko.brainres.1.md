```python
nums = [1, 3, 5, 2, 4]
for n in nums:
    if n % 2 == 1:
        nums.remove(n)
print(nums)
``` -->

결과는 `[1, 5, 2, 4]`가 나오는데, 순회하는 도중에 리스트를 수정해서 원소를 건너뛰기 때문이에요.

**왜 건너뛰나요?** `for`는 인덱스(0, 1, 2…)로 리스트를 읽어요. 원소를 지우면 뒤 원소들이 앞으로 한 칸씩 당겨지는데, 인덱스는 그대로 증가해요.

1. 인덱스 0: `1`은 홀수라서 지워요 → `[3, 5, 2, 4]`
2. 인덱스 1: 이제 `5`를 읽어요. `3`은 인덱스 0으로 당겨져서 검사 없이 건너뛰어요. `5`를 지워요 → `[3, 2, 4]`
3. 인덱스 2: `4`는 짝수예요.
4. 인덱스 3: 끝나요.

그래서 `3`이 남아야 하는데, 실제로는 `1`과 `5`가 지워지고 `3`이 남은 `[3, 2, 4]`가 나와요. (위에서 제가 쓴 `[1, 5, 2, 4]`는 틀렸고, 정확한 출력은 `[3, 2, 4]`예요.)

**해결법:** 새 리스트를 만드는 방법이 가장 간단해요.

```python
nums = [1, 3, 5, 2, 4]
nums = [n for n in nums if n % 2 == 0]
print(nums)  # [2, 4]
```

원래 리스트 객체를 그대로 유지해야 하면 슬라이스 대입을 써요.

```python
nums[:] = [n for n in nums if n % 2 == 0]
```

복사본을 순회하는 방법도 있어요. `for n in nums[:]:`로 바꾸면 원본을 지워도 순회가 흔들리지 않아요.
