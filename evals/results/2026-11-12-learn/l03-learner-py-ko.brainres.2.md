반복하는 도중에 리스트에서 원소를 지우면 인덱스가 밀려서 일부 원소를 건너뛰기 때문이에요. 결과는 `[3, 2, 4]`로 나와요.

과정을 따라가 볼게요.

1. 인덱스 0: `n=1` → 홀수라 삭제. 리스트는 `[3, 5, 2, 4]`
2. 인덱스 1: `n=5` (3은 인덱스 0으로 밀려서 건너뜀) → 삭제. 리스트는 `[3, 2, 4]`
3. 인덱스 2: `n=4` → 짝수라 유지
4. 인덱스 3: 길이가 3이라 종료

반복자는 "다음 인덱스"만 기억하기 때문에, 삭제로 앞당겨진 원소를 볼 수 없어요.

해결법은 새 리스트를 만드는 거예요. 가장 파이썬다운 방법은 리스트 컴프리헨션이에요.

```python
nums = [1, 3, 5, 2, 4]
nums = [n for n in nums if n % 2 == 0]
print(nums)  # [2, 4]
```

원래 리스트 객체를 그대로 수정해야 한다면 슬라이스 대입을 쓰세요.

```python
nums[:] = [n for n in nums if n % 2 == 0]
```

다음으로, 복사본을 순회하는 방식(`for n in nums[:]:`)도 직접 바꿔서 돌려 보세요. 동작 차이가 눈에 들어올 거예요.
