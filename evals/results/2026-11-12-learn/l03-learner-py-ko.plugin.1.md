순회하는 중에 리스트를 바꾸면 요소를 건너뛰기 때문에, 결과가 `[3, 2, 4]`로 나와요.

**왜 그런가요?** `for`는 인덱스 번호로 리스트를 읽어요. 요소를 지우면 뒤 요소들이 앞으로 당겨지는데, 인덱스는 그대로 한 칸 더 가요.

1. 인덱스 0: `1`이 홀수라서 지워요. 리스트는 `[3, 5, 2, 4]`가 돼요.
2. 인덱스 1: `3`이 아니라 `5`를 읽어요. `3`을 건너뛴 거예요. `5`를 지워요. 리스트는 `[3, 2, 4]`가 돼요.
3. 인덱스 2: `4`는 짝수라서 그대로 둬요. 순회가 끝나요.

**고치는 법:** 지울 게 아니라 남길 것으로 새 리스트를 만드세요.

```python
nums = [1, 3, 5, 2, 4]
nums = [n for n in nums if n % 2 == 0]
print(nums)  # [2, 4]
```

원본 리스트 객체를 꼭 유지해야 한다면 `nums[:] = [n for n in nums if n % 2 == 0]`처럼 써요. 복사본을 순회하는 `for n in nums[:]:` 방법도 있어요.
