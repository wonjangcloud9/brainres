```python
nums = [1, 3, 5, 2, 4]

    if n % 2 == 1:
        nums.remove(n)

``` -->

결과는 `[3, 2, 4]`가 나옵니다. 기대한 `[2, 4]`와 다르죠.

## 원인

리스트를 순회하는 도중에 그 리스트를 수정했기 때문입니다. `for`문은 내부적으로 "현재 인덱스"를 하나씩 늘려가며 요소를 가져오는데, 요소를 지우면 뒤의 요소들이 앞으로 당겨져서 인덱스가 어긋납니다.

실제 진행 과정:

| 단계 | 인덱스 | 리스트 상태 | n | 동작 |
|---|---|---|---|---|
| 1 | 0 | `[1, 3, 5, 2, 4]` | 1 | 홀수 → 삭제 → `[3, 5, 2, 4]` |
| 2 | 1 | `[3, 5, 2, 4]` | 5 | 홀수 → 삭제 → `[3, 2, 4]` |
| 3 | 2 | `[3, 2, 4]` | 4 | 짝수 → 유지 |

1을 지우면 3이 인덱스 0으로 당겨지는데, 다음 순회는 인덱스 1부터라서 **3은 검사도 못 하고 건너뜁니다.**

## 해결 방법

**1. 리스트 컴프리헨션 (가장 권장)**
```python
nums = [n for n in nums if n % 2 == 0]
```

**2. 복사본을 순회**
```python
for n in nums[:]:
    if n % 2 == 1:
        nums.remove(n)
```

**3. `filter` 사용**
```python
nums = list(filter(lambda n: n % 2 == 0, nums))
```

보통은 1번이 가장 읽기 쉽고 파이썬답습니다. 원본 리스트 객체를 유지해야 하는 경우(다른 곳에서 같은 리스트를 참조 중일 때)에는 `nums[:] = [n for n in nums if n % 2 == 0]`처럼 슬라이스 대입을 쓰면 됩니다.
