<!-- Q: 도커랑 가상머신 차이가 뭐야? -->

핵심 차이는 **OS 커널을 공유하느냐**예요. 도커 컨테이너는 호스트의 커널을 같이 써요. 가상머신(VM)은 OS 전체를 따로 하나 더 띄워요.

- **커널**: OS의 핵심이에요. 하드웨어와 프로그램을 연결해요.
- **게스트 OS**: VM 안에 따로 설치한 OS예요.

| 항목 | 도커 컨테이너 | 가상머신 |
|---|---|---|
| 구조 | 호스트 커널 공유 | 게스트 OS 통째로 실행 |
| 속도·크기 | 보통 1초 안팎 시작, 수십~수백 MB | 보통 수십 초 이상, 수 GB |
| 격리 강도 | 상대적으로 약함 | 강함 |
| 다른 OS 실행 | 호스트와 같은 커널 계열만 | 윈도우, 리눅스 등 거의 다 |

컨테이너는 커널을 공유해서 가볍고 빨라요. 대신 커널에 취약점이 생기면 여러 컨테이너가 함께 위험해질 수 있어요. VM은 OS를 통째로 띄워서 무거워요. 그 대가로 서로 확실하게 분리돼요.

쓰시는 macOS에서는 사정이 조금 달라요. 도커는 리눅스 커널이 있어야 돌아가요. 그래서 Docker Desktop은 안에 작은 리눅스 VM을 띄워요. 컨테이너는 그 VM 위에서 실행돼요.

용도는 이렇게 나누면 돼요.
- **도커**: 앱 배포, 팀 개발 환경 통일
- **VM**: 다른 OS 실행, 강한 보안 격리

Docker Desktop이 설치되어 있다면 터미널에서 `docker run --rm hello-world`를 실행해 보세요. 몇 초 안에 컨테이너가 뜨고 사라지는 걸 직접 볼 수 있어요.
