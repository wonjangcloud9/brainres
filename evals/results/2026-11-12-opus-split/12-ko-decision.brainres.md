**값이 바뀌면 리스트, 안 바뀌면 튜플을 쓰세요.** 튜플은 만든 뒤 수정할 수 없어요. 이를 "불변(immutable)"이라고 해요.

| | 리스트 `[1, 2]` | 튜플 `(1, 2)` |
|---|---|---|
| 수정 | 추가·삭제·변경 가능 | 불가능 (불변) |
| 주 용도 | 같은 종류 여러 개 | 의미가 다른 값 묶음 |
| 딕셔너리 키 | 못 써요 | 쓸 수 있어요 |
| 메모리·속도 | 조금 더 무거워요 | 조금 더 가벼워요 |

## 예시

```python
# 장바구니: 계속 추가되니까 리스트
cart = ["사과", "우유"]
cart.append("빵")

# 좌표: 위도·경도 한 쌍이 고정이라 튜플
point = (37.5, 127.0)
places = {point: "서울"}   # 튜플은 키로 쓸 수 있어요

# 함수에서 값 여러 개 돌려줄 때도 튜플
def min_max(nums):
    return min(nums), max(nums)

low, high = min_max([3, 1, 4])
```

## 판단 기준

1. 나중에 값을 바꿀 일이 있나요? 있으면 리스트예요.
2. 위치마다 의미가 다른가요? 예를 들어 (이름, 나이)라면 튜플이에요.
3. 딕셔너리 키나 `set`에 넣어야 하나요? 그러면 튜플이에요.

튜플 안에 리스트가 있으면 **키로 못 써요**. `({1: 2}, [1])` 같은 튜플은 `TypeError`가 나요.

속도 차이는 대부분 체감하기 어려워요. 그러니 성능보다 의미를 기준으로 고르세요.
